# TerryDirector

AI 视频镜头生成任务工作台。当前为 **HTML / CSS / JavaScript 静态交互 Demo**，不连接 ComfyUI，不做 React 拆分。

## Demo v0.6.11

**时间线片段可读性继续优化**：片段起点由硬质边界符号改成只在片段内部扩散的“竖条霓虹灯”——未选中为紫色、选中为橙色；片段第一行信息上移、第二行状态下移，保持原高度但增加两行呼吸空间。总编排时长、橙色片段秒数、8px 重叠引线和后续联动均保持不变。

**此前调整**：未选中的时间线片段也有清晰的常驻起点标识；工具栏左侧新增大号橙色总编排时长，所有片段上的秒数也为橙色。总时长与播放头当前位置分开，拖动、尾部联动、撤销和取消即时更新。重叠不重复计时，空项目显示零。

**沿用视觉**：选中的时间线片段改为橙色边线与低饱和暖色填充；播放头和重叠关系仍用紫色。外部背景恢复之前的深灰蓝，并加强外壳柔和投影，留白及内部布局不变。资产引用暖橙、台词块珊瑚红继续保留。详见 [配色层级](docs/04_COLOR_BALANCE.md)。

- 「后续联动」默认开启。移动片段时后续片段同距移动；拉长或缩短尾部时，后续片段按尾部的实际变化量平移，保持与下一片段的间距 / 重叠和后续片段时长。头部裁剪独立；关闭联动后移动 / 裁剪均只影响当前片段。一次拖动一步撤销，Esc 可取消整次操作。

- 提示词内的图片、音视频、语法与对白标签统一行内居中；中间资产区按用户手动调整的截图设为默认 680px，紧凑卡片一行四格，缩略图保持约原四分之一面积。
- 分辨率改用比例 + 像素量 MP + 尺寸倍数，实时显示实际宽 × 高；默认 16:9 / 1.2 MP / 32 → 1504 × 832，每片段独立保存。
- 四周保留加倍留白、外部背景恢复深灰蓝并加强投影；时间线默认高度 200px，提示词标题与工具行压缩，正文获得更多空间。
- 上方从左到右为提示词、参考资产配置、固定生成预览，下方为时间线。预览窗始终保留；开关只控制画面更新，不隐藏区域或影响生成。分辨率、开关和生成按钮统一放在预览窗下方。预览仍是模拟反馈，不是模型输出。
- 提示词可视化可以直接编辑，保留纯文本切换。两种方式使用同一份原文。
- 从 Terry 的 H3 编辑器移植 `@` 引用与 `/` 语法菜单：全部 46 条命令、五类入口、镜头运动子菜单及 20 种运镜。支持搜索、键盘选择、标签更换、对白编辑、原文复制与撤销。
- 中间区域是整个项目共用的资产池，切换片段保留同一列表。顶部仅有两个不同入口：**上传资产**（选择新文件）、**从 ComfyUI input 选取**（复用已有文件）；移除重复的“添加素材”格子。两者只入池，不自动写入片段。
- Demo 的上传只在浏览器本页读取，不实际上传；input 选择器使用明确标注的示例目录，没有读取真实 ComfyUI input。支持多选、按文件名 / 子目录搜索、取消、重复来源去重和一步撤销；接入真实目录留到 ComfyUI 插件阶段。
- 所有片段可通过插入引用、`@` 菜单或拖拽使用池内素材。点击素材仍打开独立大图 / 媒体灯箱。
- 资产按类型使用稳定项目编号；当前片段引用有轻量标记。删除提示词标签只取消片段引用；从资产池删除需要确认，会清理相关片段标签并支持一起撤销。
- 已认可的单行时间线、自动重叠、引线标记、进度及耗时不变。没有 AI 增强或版本管理。

## 查看与发布

根目录 `index.html` 是静态入口，保留 `src/`、`assets/` 相对位置即可。无安装、编译或外部 CDN。下载包同时提供内联的 `打开Demo.html`。

GitHub Pages：Settings → Pages → Deploy from a branch → main → /(root)。`.nojekyll` 保留。预计地址：`https://terry-xu-2077.github.io/TerryDirector/`；提交代码不等于已完成 Pages 部署。

数据只在当前页面暂存，刷新还原；导出配置不包含素材文件。模拟生成约 6 秒，不调用模型。
