# TerryDirector

AI 视频镜头生成任务工作台。当前为 **HTML / CSS / JavaScript 静态交互 Demo**，不连接 ComfyUI，不做 React 拆分。

## Demo v0.6.13 · 工作区布局与常驻生成动作

按用户确认的示意图调整桌面工作区：

| 区域 | 内容与行为 |
| --- | --- |
| 左侧，默认约 46% | 提示词编辑占满工作区高度 |
| 右侧上排左侧，默认占右区宽度 32% | 常驻生成预览，画面开关移到标题右侧；Demo 非模型输出说明保留在预览画面区域 |
| 右侧上排右侧，占上排其余宽度 | 项目资产池，紧凑卡片与内部滚动 |
| 右侧下排，跨满右侧 | 集中现有生成参数，参数内容内部滚动；主生成按钮位于独立固定底栏，滚动参数时始终可见 |
| 底部，跨全宽 | 原有单行时间线 |

右侧上排默认占右区高度 50%，默认尺寸按可用空间和各区域最小尺寸调整。三个工作区分隔线与原时间线分隔线均支持拖动、方向键每次 12px 微调、双击恢复默认。视口宽度不超过 900px 时，依次堆叠提示词、预览、资产、参数和时间线；资产池与参数面板各自固定高度并内部滚动，生成按钮仍固定在参数区域底栏内。滚动整个页面时，按钮随所属区域移动。

此布局覆盖旧三列与资产默认 680px 约定，延续已有配色、时间线和编辑交互；本轮不增加生成字段，不改变项目配置、分辨率语义或导出版本 9，也不接入后端。

### 沿用 v0.6.12 二次潜空间放大设置

右下生成参数区在分辨率之后保留 **二次潜空间放大**。这是项目共用设置，默认关闭；开启后展开「放大模型」与「高清阶段步数」。切换片段保留同一份配置，空项目也可先设置；开关和参数支持撤销 / 重做，新建项目或重置 Demo 恢复默认。

- 模型默认为自动选择，内部保存空字符串；真实接入时由参考节点选择兼容 H3 的模型。`minimax_h3_latent_upscaler_3d_bf16.safetensors` 仅是明确标注的示例名称，当前没有扫描本地模型。
- 高清阶段步数默认 4，必须为正整数，真实接入时还须少于工作流的实际总步数。界面以「总计 8 步时，4 步低清 + 4 步高清」解释分配；8 仅为示例，当前不作为步数上限或导出参数。
- 现有分辨率仍是最终目标。低清阶段约半宽半高，并按模型网格对齐；界面不增加倍率控件，也不将最终宽高再乘以 2。
- 普通参数保持中性，开启状态沿用紫色；导出格式保持版本 9，设置保存在 `project.latentUpscale`。本轮仍只配置和演示 UI，不运行潜空间放大或真实生成。

这项补充沿用参考节点固定提交 `a81f13b8af4a162467cec4dc377f40b7354d7ffc` 的 [`_selflift_settings`](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector/blob/a81f13b8af4a162467cec4dc377f40b7354d7ffc/minimax_h3_finite_segments.py#L43-L91) 设置语义；详细约定见 [UI 实现蓝图 §9.2](docs/06_UI_IMPLEMENTATION_BLUEPRINT.md#92-二次潜空间放大v0612-补充)。

### 保留 v0.6.11 视觉与交互基线

**时间线片段可读性继续优化**：片段起点由硬质边界符号改成只在片段内部扩散的“竖条霓虹灯”——未选中为紫色、选中为橙色；片段第一行信息上移、第二行状态下移，保持原高度但增加两行呼吸空间。总编排时长、橙色片段秒数、8px 重叠引线和后续联动均保持不变。

**此前调整**：未选中的时间线片段也有清晰的常驻起点标识；工具栏左侧新增大号橙色总编排时长，所有片段上的秒数也为橙色。总时长与播放头当前位置分开，拖动、尾部联动、撤销和取消即时更新。重叠不重复计时，空项目显示零。

**沿用视觉**：选中的时间线片段改为橙色边线与低饱和暖色填充；播放头和重叠关系仍用紫色。外部背景恢复之前的深灰蓝，并加强外壳柔和投影，留白与内部配色延续。资产引用暖橙、台词块珊瑚红继续保留。详见 [配色层级](docs/04_COLOR_BALANCE.md)。

- 「后续联动」默认开启。移动片段时后续片段同距移动；拉长或缩短尾部时，后续片段按尾部的实际变化量平移，保持与下一片段的间距 / 重叠和后续片段时长。头部裁剪独立；关闭联动后移动 / 裁剪均只影响当前片段。一次拖动一步撤销，Esc 可取消整次操作。

- 提示词内的图片、音视频、语法与对白标签统一行内居中；资产池保留紧凑卡片与约 52px 高缩略图，卡片列数适配右上区域的可用宽度。
- 分辨率改用比例 + 像素量 MP + 尺寸倍数，实时显示实际宽 × 高；默认 16:9 / 1.2 MP / 32 → 1504 × 832，每片段独立保存。
- 四周保留加倍留白、外部背景恢复深灰蓝并加强投影；时间线默认高度 200px、最大 400px，实际拖动上限按视口余量收紧以保留工作区和生成按钮；提示词标题与工具行压缩，正文获得更多空间。
- 预览窗始终保留，标题右侧的开关只控制画面更新，不隐藏区域或影响生成。预览仍是模拟反馈，非模型输出说明清楚显示在画面区域。
- 提示词可视化可以直接编辑，保留纯文本切换。两种方式使用同一份原文。
- 从 Terry 的 H3 编辑器移植 `@` 引用与 `/` 语法菜单：全部 46 条命令、五类入口、镜头运动子菜单及 20 种运镜。支持搜索、键盘选择、标签更换、对白编辑、原文复制与撤销。
- 右上资产区域是整个项目共用的资产池，切换片段保留同一列表。顶部仅有两个不同入口：**上传资产**（选择新文件）、**从 ComfyUI input 选取**（复用已有文件）；移除重复的“添加素材”格子。两者只入池，不自动写入片段。
- Demo 的上传只在浏览器本页读取，不实际上传；input 选择器使用明确标注的示例目录，没有读取真实 ComfyUI input。支持多选、按文件名 / 子目录搜索、取消、重复来源去重和一步撤销；接入真实目录留到 ComfyUI 插件阶段。
- 所有片段可通过插入引用、`@` 菜单或拖拽使用池内素材。点击素材仍打开独立大图 / 媒体灯箱。
- 资产按类型使用稳定项目编号；当前片段引用有轻量标记。删除提示词标签只取消片段引用；从资产池删除需要确认，会清理相关片段标签并支持一起撤销。
- 已认可的单行时间线、自动重叠、引线标记、进度及耗时不变。没有 AI 增强或版本管理。
