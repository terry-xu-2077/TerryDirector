# TerryDirector · SelfLift 分阶段工作流

**默认示例已更新（2026-10-22）**：低清先审片，确认后再运行高清；高清转场只使用学习式 H3 3D Latent Upscaler，不执行中间 VAE 解码→放大→重新编码，不提供 SelfLift-zero 像素锚或 `nearest` 降级路线。

## 默认参数（工作流③）

- **模型**：`minimax_h3_fl2va_bf16.safetensors`
- **CLIP**：`qwen3vl_32b_minimax_h3_int8_convrot.safetensors`
- **视频 VAE**：`minimax_h3_video_vae_int8_convrot.safetensors`
- **音频 VAE**：`minimax_h3_audio_vae_fp32.safetensors`
- **分辨率**：16:9；示例工作流 JSON 原始高清目标 0.8 MP，自动推导低清 0.2 MP（低清 608×352、高清 1216×672）；预演台新建任务默认覆盖为 2.0 MP（低清 0.5 MP，实际 960×544 → 1888×1088），并按当前宽高比重新计算实际尺寸；124 帧
- **采样**：`BasicScheduler(simple, 8)` → `H3SigmaRefiner(extra_steps=1, start_at_sigma=0.7, end_at_sigma=0, spacing=cosine)` → `SplitSigmas(step=6)`
- **Seed / CFG**：固定 seed=8，CFG=1。低清原生采样器和检查点节点共用同一个 SeedNode，避免两处种子不一致。
- **高清转场**：`minimax_h3_latent_upscaler_3d_conv_v1_bf16.safetensors`
- **高清空间分块**：默认关闭；模式 manual、4 块、axis auto（只有开启开关后才生效）
- **低清预览**：工作流①、③、④使用 TerryDirector 自带的「采样预览」MODEL 包装器，以 `taeh3.safetensors` 解码，实时通过 JPEG/动态 WebP 发送采样步骤，不再发送 KJNodes 的分片 H.264 MP4。完成低清并保存 SelfLift 检查点时，后端直接从完整 `low_clean` H3 视频 latent 中抽取分布于全片的采样帧，编码成指定 4–20 秒的普通 `sampling_preview.mp4`。预览采用压缩采样帧（最高 72 帧）与 12 FPS 重复帧补足，不等同于高清 VAE 的完整帧率/画质。「采样预览」与「VAE 解码」是独立开关：可分别启用，也可同时启用；VAE 解码会额外保存完整有声 `review.mp4`。默认启用 VAE 解码，采样预览默认关闭。

`H3SigmaRefiner` 增加一个低噪修整步；在完整 Sigma 日程上从第 6 步分段，因此高清会继续执行余下日程。检查点必须与对应模型、条件、目标分辨率和 Sigma 日程兼容。

**预览异常恢复（2026-10-30）**：原生预览直接在 ComfyUI 后端落盘，不依赖浏览器在线或事后抢救 KJNodes 的分片 MP4。写入采用临时文件、完整解码与时长校验，再原子替换检查点内的视频。预览失败不会删除低清检查点。对于以前已完成但没有预览、或预览只有极短时间的任务，在预演台选中低清完成任务，切到「采样预览」，点击 **「重建预览」**：后端读取已有检查点中的 `clean_0` latent，以 `taeh3.safetensors` 直接重建完整预览，不重新运行采样。旧版 KJ 工作流配置在任务提交时自动转换为原生预览节点；推荐使用已经更新的示例工作流重新配置。

**统一输入**：工作流①、③、④使用 `TerryDirector 双采样分辨率选择器`，**只有一个「高清百万像素」浮点输入**；低清 MP 由节点自动按高清 MP ÷ 4 计算，无需额外公式。低清条件和目标高清 Latent 使用同一个时长公式（默认 5 秒 → 124 帧），原生低清采样与检查点共用同一 SeedNode。工作流②从磁盘检查点恢复高清分辨率，因此不另设目标分辨率控件。

## 工作流③使用方式

1. 第一次运行点击蓝色 **「生成预演」** 按钮；低清采样完成后同时保存检查点和独立低清审片视频，高清分支不会执行。
2. 点击 ComfyUI 左侧 **预演台** →「打开预演台」；可切换检查点中的 VAE 解码视频与采样预览。文件位于 `output/TerryDirector/checkpoints/<id>/review.mp4` 与 `sampling_preview.mp4/.webp/.jpg`。通过后点击绿色 **「继续高清」** 按钮或在任务管理器中提交高清续采；均不重跑低清。
3. 工作流中的 LoadImage 节点示例指向 `黄昏盐滩独行宇航员镜头首帧图片生成.jpg`。直接运行原始工作流时，可替换或断开该示例输入；通过预演台创建 H3 任务时，这类原有媒体加载节点会被忽略，参考资产改由任务资产槽位直接绑定到 H3 节点。
4. 工作流①和②可以分开使用，但保存与读取必须对应同一组兼容参数；切换模型、参考条件、分辨率或 Sigma 日程时，请重新生成检查点。

**自定义工作流**：配置时自动检查 SelfLift 暂停节点的 `low_clean` 是否与 `VAEDecode` / `VAEDecodeAudio` 共用同一段低清 `SamplerCustom.denoised_output`。若这两路接入 `VHS_VideoCombine`，预演台自动识别该节点为低清 VAE 终点，配置界面显示节点编号。选择「VAE 解码预览」提交时，**只在本次独立 API 任务快照内**将该 VHS 输出转换为 `TerryDirectorLowresReviewSave`（使用原有解码画面、音频与暂停节点的检查点 ID），直接写入 `review.mp4`；原画布的 VHS 节点和高清保存线路不改变，也不会重复保存两个视频。已有 `TerryDirectorLowresReviewSave` 的工作流继续照旧使用。之前配置但未识别低清 VHS 的草稿任务也会在启动前自动重新识别，无需重新连接节点。

## 预演台（侧边栏入口）

ComfyUI 左侧边栏的「预演台」顶部复用时间线节点的 TerryDirector 品牌 Logo，保留「打开预演台」按钮，下方显示**只读任务概览**：任务名称、六种状态、创建时间和最近一次低清/高清生成时间；侧栏不能编辑或运行任务。任务概览与主窗口使用同一任务接口，侧栏可见时定期刷新。「配置工作流」只在预演台主窗口中提供。
工作流设置只做一次，日常新建任务不用接触节点映射：

1. **配置工作流**：导入 ComfyUI 工作流 JSON，或直接使用当前画布；选择 SelfLift 暂停/继续节点；检测到唯一的 `MiniMaxH3ReferenceToVideo` 时，自动绑定其 `prompt` 输入及图片/视频/音频参考输入端，种子输入仍需明确指定。存在多个 H3 节点时选择目标节点；普通非 H3 工作流仍可手动指定可编辑的提示词输入节点。每份配置独立保存在 `output/TerryDirector/preview_stage/templates/<配置ID>/` 下的 `config.json`、`workflow.json` 和 `api_prompt.json`，并由同级 `templates/index.json` 管理列表及默认项。支持多套工作流并列保存、改名、设置默认和单独删除；删除配置不会影响已生成的检查点。配置时一次性编译 API 工作流，后续任务只覆盖提交数据里的提示词、资产、种子及输出目标；不改 rgthree Seed / 采样器节点，也不打开新工作流标签。种子范围从实际 ComfyUI 节点定义读取，并取种子源、SamplerCustom 和暂停节点允许范围的交集。对经 SetNode/GetNode 与 TerryXu 无线总线传递的种子，也沿实际频道和 lane 追踪到采样器，不再误将总线里的「SEED」通道当作采样器。
   - **输入源选择**：普通非 H3 工作流按节点的**输出接口类型**筛选提示词候选：仅列出有 `STRING` 输出和可编辑文本控件的节点，名称前显示 `[STRING]`。识别到 H3 时直接覆盖 H3 节点自身的 `prompt` 输入，不再要求选择外部提示词源。种子仅列出有 `INT` 输出和可编辑种子控件的节点，名称前显示 `[INT]`。候选多于一个时由用户手动选择；普通工作流不沿总线或切换分支推断输入源。配置只覆盖提交的 API 工作流输入，不修改画布；保存失败会在窗口内显示原因。
2. **新建预演**：填写镜头名称、提示词、参考资产和种子；新增 **4–20 秒时长滑块（默认 15 秒）**，以及高清 MP 下拉菜单（默认 2.0 MP，根据当前工作流宽高比自动显示低清 MP 与低/高清实际宽高，低清 MP = 高清 MP ÷ 4）；采样预览与 VAE 解码分别以独立开关呈现，不再互斥。时长同时覆盖 H3 条件节点和 EmptyMiniMaxH3LatentAV 的 `length`，按工作流统一公式换算 24fps 帧数（15 秒对应 362 帧）。修改只应用在本任务提交的 API 快照，不改变 ComfyUI 当前画布。每次新建时 Seed 会按已配置工作流的种子源与采样器有效范围**自动随机**，用户可再按骰子按钮重抽或手动输入。点击「创建任务」**只在预演台保存任务草稿、显示到左侧列表**，不会调用 ComfyUI 队列。草稿持久保存在 `output/TerryDirector/preview_stage/drafts/`，重启后可继续编辑；从列表手动点击「开始预演」才会执行低清，低清完成后可选择「继续高清」或批量高清。H3 工作流按原生节点的完整输入上限提供参考资产槽位：最多 9 张图片、3 段视频、3 路独立音频；每段视频最多自动配对一条对应音轨（共最多 3 路），不额外占用独立音频槽位。即使原工作流只展开了部分动态输入，预演任务仍可使用 H3 节点 schema 支持的完整数量。预演任务会忽略原工作流中已有的 `LoadImage`、`LoadVideo`、`LoadAudio` 等资产加载节点，改用任务中选择的资产直接连接 H3。参考视频自动提取画面和音轨，分别接入 H3 视频参考及配对音频端。普通非 H3 工作流仍沿用可编辑的资产加载节点。参考资产以紧凑缩略图网格展示，可在资产选择器中搜索、更换或上传。默认启用 **VAE 解码**，高清分辨率默认 **2.0 MP**。**采样预览** 是独立开关：开启后实时显示采样步骤，并在低清完成后保存 `sampling_preview.mp4`；**VAE 解码** 开启后额外执行完整的视频/音频解码支路并保存检查点目录里的 `review.mp4`。两个开关可单独启用，也可同时启用。
   - **完整 H3 富文本编辑**：预演台复用 TerryXu H3 编辑器的富文本标签渲染与共享菜单。左侧扩展编辑区显示可点击的 Subject / Picture / Video / Audio / Shot / Speaker / 时间戳 / 运镜 / 保留关系等标签；`<Picture N>` 显示当前任务参考图片的**行内缩略图**。对白块可在标签内修改语言、编辑台词，镜头编号、说话人、时间戳与运镜标签可点击修改。右侧为独立滚动的资产缩略图网格，修改图片时行内引用随任务重新渲染更新。支持 `@`（含全角 `＠`）资产菜单、`\\` / `/`（含全角字符）H3 全分类命令菜单、中文输入法与键盘导航。
   - **富文本 / 原文**：切换仅改变编辑呈现，提交仍通过原版 H3 序列化规则生成纯 STRING，绝不把 HTML 或缩略图写入采样器。完整富文本逻辑来自同一用户仓库 TerryXu-nodes 的 `h3_rich_text.js` / `h3_shared_menus.js`，在 TerryDirector 内独立适配并记录上游来源，避免运行时强依赖另一个节点包。
   - **采样预览实时画面**：新节点每个实际采样步通过 `terrydirector_preview` 事件传送 JPEG/动态 WebP；WebSocket 数据只用于实时显示，不作为最终 MP4 的输入。检查点保存节点通过最终 `low_clean` latent 独立完成标准 MP4，浏览器断线不影响它。旧配置的 KJ 预览事件仍可作为回退，但新流程不要求安装 KJNodes。

   - **高清完成后直接查看成片**：预演台把当前任务实际执行的 `SaveVideo`（或 `VHS_VideoCombine`）输出文件关联到检查点，高清完成后右侧自动切换为「高清成片」，仍保留「采样预览」及「VAE 解码」用于低清对比。高清文件继续留在 ComfyUI 原始 `output` 目录，不复制大文件；关联的路径经过输出目录边界验证并写入检查点 `task.json`。已有高清完成任务可凭精确 `prompt_id` 与高清保存节点 ID，从仍存在的 ComfyUI 历史结果自动恢复文件关联；若历史已清空且未记录过输出文件，不能凭名称推断或保证找回。
   - **低清/高清每步采样进度**：预演台任务列表在状态标签右侧显示 ComfyUI 原生采样事件对应的 tqdm 风格短行（例如 `33%|███▎      | 1/3 [11:28<22:56, 688.33s/it]`）。步数和百分比来自实际 `progress` / `progress_state` 事件；耗时和剩余时间由本次任务时钟估算，并非读取终端原始文本。按 `prompt_id` 和实际 Sampler 节点隔离，任务没有开始/非采样节点不显示；进度仅更新文本 DOM，不刷新视频播放器或影响其他排队任务。低清与高清阶段分别显示各自的采样进度，任务结束自动清除即时状态。
   - **六个任务状态与计时**：每个任务依次支持「低清待生成、低清生成中、低清完成、高清待生成、高清生成中、高清完成」。排队中的低清仍显示「低清待生成 · 已排队」，高清显示「高清待生成 · 已排队」。状态由执行开始、检查点写入和任务成功/失败事件更新；不能仅因为提交队列就标记完成。记录任务创建、低清开始/完成、高清开始/完成时间，并显示两阶段实际耗时。失败/中断保留错误信息，可在待生成状态手动重新提交。
3. **继承已有任务**：新建预演时可把已由预演台生成、且保留完整工作流快照的任务作为来源，继承工作流、提示词、资产和预览类型；**Seed 默认重新随机**，不沿用旧任务的 Seed。仅编辑原任务时保持原 Seed，仍可手动通过骰子按钮随机；原检查点不变。
4. **管理与批量操作**：左侧顶部支持按六种任务状态筛选；「全选」仅选择当前筛选结果。底部批量按钮随所选任务状态变化：低清待生成 →「批量开始预演」，低清完成 →「批量高清续采」；生成中、已排队、高清已完成以及混合状态不允许重复提交。勾选任务还可批量删除。删除前二次确认；10 条及以上需要输入「删除」，正在被 ComfyUI 运行或排队使用的检查点禁止删除。

每次预演存一份 `state.safetensors` 和 `manifest.json`，以及按开关启用的 `sampling_preview.mp4`（采样预览）和 `review.mp4`（完整 VAE 解码）。`taeh3.safetensors` 需放在 ComfyUI 的 `models/vae_approx` 下。原生预览保存失败时，检查点仍能继续高清；可以之后使用「重建预览」。原有检查点未保存 `task.json` 快照时不能无损继承提示词资产，但可查看和重建检查点预览。

**运行边界**：原生模型解码、MP4 保存和从旧检查点重建已实现；仍需在正式 ComfyUI、RTX 3090 和用户实际 H3 权重上验证质量、解码开销及 GPU 显存峰值。

## 高清 MODEL 输入口

`TerryDirectorSelfLiftHighres` 现只有一个 **「高清采样 MODEL」**。工作流 ②/③ 直接连接基础 H3 MODEL；工作流 ④ 将 `MiniMaxChunkFeedForward` 的最终优化 MODEL 直接连接此输入。要换模型或注意力优化策略，只需调整上游连线，不需要第二个 MODEL 插口。旧版含两个 MODEL 口的画布请重新导入已更新的示例，或手动删掉并重建高清节点以避免旧槽位错接。

## 独立工作流

- **① 低清保存**：同样使用 BF16 FL2VA、INT8 ConvRot CLIP、CFG=1、seed=8、8 步 simple 日程 + H3 Sigma Refiner，低清采样约 0.2 MP，保存目标 0.8 MP latent 检查点。
- **② 高清读取**：加载与检查点兼容的 BF16 FL2VA 和 INT8 ConvRot CLIP；提示词条件使用低清 0.2 MP 尺寸；高清节点默认关闭空间分块。
- **④ 0.5→2 MP**：实际取整为低清 960×544、高清 1888×1088；保留独立高清 MODEL 链 `ModelAttentionBackend → MiniMaxLowVRAMAttention(8) → MiniMaxChunkFeedForward(2,4096)`，并启用 4 块空间分块。该工作流的目标尺寸与显存压力更高，不作为默认审片样例。

## 模型要求

Upscaler 权重 `minimax_h3_latent_upscaler_3d_conv_v1_bf16.safetensors` 应放在 ComfyUI 的 `models/latent_upscale_models/` 下。高清节点只使用有效的 H3 3D Latent Upscaler；不会自动回退到 `nearest` 或 VAE 往返。

最终用于导出视频和音频的 VAE 解码仍然保留；本次移除的是高清采样前的中间 VAE 往返。

详细架构：[SELFLIFT_SPLIT_NATIVE_SAMPLER_MVP.md](../docs/SELFLIFT_SPLIT_NATIVE_SAMPLER_MVP.md)。


## 工作流节点命名

示例工作流保留 ComfyUI 节点的默认名称，不通过自定义节点标题解释用途。每个工作流内的 **Markdown Note** 节点负责说明用途、关键参数与运行顺序；实际参数仍以节点控件和本机可用模型为准。
