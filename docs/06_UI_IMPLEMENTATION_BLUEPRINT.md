## 1. 产品界面的核心原则

TerryDirector 是 **镜头生成任务编排工作台**，不是传统 NLE，也不是以播放器为核心的视频编辑器。

用户的主路径：

```text
选择时间线片段
      ↓
编辑提示词
      ↓
从项目资产池引用素材
      ↓
设置生成规格
      ↓
提交生成
      ↓
查看生成过程反馈
      ↓
继续编排下一个片段
```

任何新功能进入常驻界面前，都必须先回答：

> 它是否直接服务于“编排镜头生成任务”？

如果答案是否定的，不增加常驻面板。

---

## 2. 部署形态与 UI 边界

TerryDirector 最终不是桌面应用。

```text
ComfyUI Custom Node
        │
        ├─ 共用 Python / GPU / Workflow / Queue
        ├─ 共用 input / output / temp
        │
        └─ 启动 TerryDirector 本地 Web 工作台
                     ↓
              独立本地端口
```

ComfyUI 节点只承担：

- 服务状态
- 当前项目摘要
- 打开工作台入口

完整时间线、提示词、资产池和生成预览都在 Web 工作台中。

不要重新引入 Tauri、独立桌面 Runtime、Bridge、独立任务引擎或为未来假设场景设计的大量中间层。

---

## 3. 面向用户的术语

面向用户统一使用：

- **片段**
- **时间线片段**
- **资产池**
- **参考资产**
- **生成预览**
- **后续联动**

不使用 `Segment` 作为 UI 文案。

内部代码可以选择稳定的英文类型名，但不能渗透到用户界面。

# 4. 整体布局

## 4.1 桌面布局

**Demo v0.6.13 按用户确认的示意图采用以下区域安排：**

| 区域 | 内容 | 默认分配与行为 |
| --- | --- | --- |
| 顶栏 | 项目入口、项目名、操作说明、导出配置 | 跨全宽 |
| 工作区左侧 | 当前片段、可视化 / 纯文本提示词、`@` 引用与 `/` H3 语法 | 默认约占工作区 46%，占满时间线上方的工作区高度 |
| 工作区右侧上排左侧 | 常驻 16:9 生成预览，标题右侧为预览开关 | 默认占右侧宽度的 32% |
| 工作区右侧上排右侧 | 项目资产池、上传资产、从 ComfyUI input 选取、紧凑素材网格 | 占上排除预览与分隔线外的剩余宽度，素材区域内部滚动 |
| 工作区右侧下排 | 比例、MP、尺寸倍数、最终宽高、二次潜空间放大 | 跨满右侧，参数内容内部滚动 |
| 右下参数区底栏 | 主生成动作 | 独立固定底栏，不随参数滚动 |
| 底部 | 时间线工具栏、总编排时长、单行时间线 | 跨全宽 |

右侧上排默认占右侧高度的 50%。三个工作区分隔线分别调整左 / 右工作区、右上预览 / 资产池及右侧上下区域；与原有底部时间线分隔线一样，均支持拖动、方向键每次 12px 微调、双击恢复默认。

桌面默认比例用于初始布局，实际尺寸根据可用空间和区域最小尺寸进行限制，不再采用旧资产列固定 680px 的默认规则。

桌面布局适用于视口宽度大于 900px，拖动边界如下：

| 调整区域 | 最小尺寸与剩余空间 |
| --- | --- |
| 提示词宽度 | 至少 280px，同时给主分隔线与右区合计保留至少 505px |
| 右上预览宽度 | 至少 200px，同时给分隔线与资产池合计保留至少 285px |
| 右侧上排高度 | 至少 220px；整个工作区至少 370px，给下方参数区保留约 145px 及其固定动作底栏 |

本次只调整已存在控件的位置和滚动边界，不新增生成字段，不改变项目配置、分辨率语义或导出版本 9，不接入后端。移动布局保留同一份数据和设置。

不恢复：

- 左侧片段列表
- 右侧整列 Inspector
- 中央大型播放器
- 多轨剪辑工作区

## 4.2 外壳

工作台不是贴浏览器边缘的全屏平面。

外壳要求：

- 浏览器四周留白：`clamp(24px, 6vmin, 80px)`
- 外部背景：深灰蓝，而不是纯黑
- 视觉约为 `#242632 → #1D1F29`
- 应用本体有圆角和细亮边
- 使用明显但柔和的下方投影
- 同时保留贴近外壳的接触阴影

目标是类似最初配色参考图的“设备浮在背景上”的层次，而不是网页卡片感。

当前外壳阴影由 Theme Contract 统一控制，业务组件不得自行增加另一套大阴影。

# 6. 提示词编辑区

提示词是主要创作区域。

## 6.1 顶部压缩结构

当前固定节奏：

```text

下间距             6px

合计              78px
```

不能重新膨胀成大标题区。

片段身份行：

- 片段编号

工具行：

- 提示词
- `@ 引用素材`

---

## 6.2 一份 Prompt，两种编辑表现

每个片段只保存一份 Prompt。

```text
clip.prompt
     │
     ├─ 可视化编辑
     └─ 纯文本编辑
```

两种模式不是两份数据。

切换模式必须：

- 不丢换行
- 不丢标签
- 不改变原始 H3 语句
- 不生成隐藏副本

当前不做 AI 增强，不显示 AI Prompt 标签页，不显示“采用增强结果”。

---

## 6.3 可视化编辑器

可视化模式 **必须可编辑**，不是预览器。

支持：

- 输入
- 删除
- 换行
- 选中
- 复制
- 剪切
- 粘贴
- Undo / Redo
- 中文输入法组合输入

格式化标签的可见中文只是表现层，原始文本仍保存为 H3 语法。

全选复制时不能遗漏格式化标签。

---

## 6.4 `@` 资产菜单

`@` 菜单读取 **整个项目资产池**。

不是只读取当前片段已有引用。

菜单显示：

- 图片 / 视频 / 音频
- 项目稳定编号
- 文件名
- 图片缩略图
- 搜索 / 过滤

选择后在当前光标位置插入对应引用。

点击已有资产引用标签可以更换绑定素材。

---

## 6.5 `/` H3 菜单

来源以 Terry H3 Prompt Editor 为准。

保留五类：

- 结构
- 镜头
- 对白
- 保留关系
- 任务类型

镜头分类下保留镜头运动子菜单和全部 **20 种运镜**。

菜单交互：

```text
↑ ↓      选择
→        进入分类
←        返回
Enter    确认
Tab      确认
Esc      关闭
继续输入  搜索
```

支持：

- 镜头编号修改
- 说话人编号修改
- 时间戳修改
- 运镜切换
- 对白语言切换
- 对白正文直接编辑

`non_diegetic_music:` 插入时下一行默认 `N/A`。

# 7. 项目资产池

右上资产区域不是“当前片段参考列表”。

它是：

> **项目级全局资产池**

切换时间线片段时：

- 资产列表不变化
- 滚动位置不变化
- 只更新“当前片段正在引用”的轻量状态

---

## 7.1 尺寸

资产池位于右侧上排右侧，占该排除预览与分隔线外的剩余宽度；预览默认占右侧宽度的 32%。两者之间的分隔线支持拖动、方向键每次 12px 微调，双击恢复当前布局默认比例。

旧三列布局的资产默认 680px 是 v0.6.11 的历史记录，已由 v0.6.13 用户确认布局覆盖。

资产网格默认：

- 卡片列数随区域可用宽度适配
- 缩略图高约 **52px**
- 紧凑卡片
- 素材增加后自动换行
- 资产区域内部滚动

不要恢复大卡片或单张素材占半栏的样式。

---

## 7.2 资产池入口

顶部只保留两个入口：

### 上传资产

用户选择新的图片 / 视频 / 音频。

正式实现中：

```text
用户文件
  ↓
TerryDirector
  ↓
ComfyUI 管理的 input
  ↓
加入当前项目资产池
```

### 从 ComfyUI input 选取

用于复用 input 中已经存在的素材：

- 浏览子目录
- 搜索文件名
- 多选
- 已入池标记
- 不重复上传

这两个入口必须明确区分。

不要再增加：

- “从项目选取”
- 网格末尾“添加素材”卡片

因为资产池本身已经是项目素材浏览器。

---

## 7.3 稳定编号

项目级素材按类型稳定编号：

```text
Picture 1
Picture 2
Video 1
Audio 1
...
```

编号：

- 只在加入项目时分配一次
- 切换片段不变化
- 删除其他素材不重排
- 删除后的编号不立即复用

UI 的编号是项目稳定引用。

提交具体模型工作流时，如模型要求局部连续编号，由编译层转换，不能让 UI 自己猜。

---

## 7.4 引用与删除

片段引用资产有三种方式：

```text
资产卡片「插入引用」
@
把资产拖到目标时间线片段
```

删除提示词中的引用标签：

> 只取消该片段的引用。

资产池“删除”：

> 项目级删除。

必须确认受影响片段，并清理这些片段中的对应引用。整个删除过程应支持一步 Undo。

资产池删除不能删除 ComfyUI input 中的原始磁盘文件。

不能把素材塞进生成预览窗。

关闭灯箱时停止媒体播放并释放播放状态。

# 8. 生成预览区

生成预览位于 **右侧上排左侧的常驻区域**，右边为项目资产池，下方为跨满右侧的生成参数区。

它不是工作台视觉中心，也不是完整播放器。

## 8.1 预览窗

- 16:9
- 始终占据布局
- 不隐藏
- 不折叠
- 不回收预览所占区域

预览开关放在标题右侧，替代原来的「演示 · 非模型输出」标题附文。Demo 说明移到预览画面区域并保持清楚，演示静帧必须始终能够识别为非模型输出；不能因为移动开关而移除说明。

预览开关只控制：

> 是否显示 / 更新生成过程画面。

关闭时：

- 面板仍在
- 显示“生成预览已关闭”
- 生成任务继续
- 进度继续
- 参数仍可修改
- 不重排工作区

## 8.2 真正实现时的数据来源

正式版生成预览优先复用 ComfyUI 原生采样预览数据流。

参考 TimelineDirector / SelfLift 路径：

```text
Sampler
  ↓
latent preview callback
  ↓
TerryDirector preview transport
  ↓
常驻生成预览窗
```

# 9. 生成参数

生成参数集中放在 **工作区右侧下排**，横跨上排预览与资产池的总宽度。

参数内容内部滚动，主生成动作独立放在固定底栏；展开二次潜空间放大或滚动参数时，生成按钮必须仍然可见。提示词区底部只保留编辑提示和字数。

---

## 9.1 分辨率选择

使用 ComfyUI Resolution Selector 同一逻辑：

```text
画面比例
像素量 MP
尺寸倍数
      ↓
实际 Width × Height
```

支持比例：

- 1:1
- 2:3
- 3:2
- 3:4
- 4:3
- 9:16
- 16:9
- 21:9

计算：

```text
total_pixels = megapixels × 1024 × 1024
scale = sqrt(total_pixels / (ratioW × ratioH))

width  = round(ratioW × scale / multiple) × multiple
height = round(ratioH × scale / multiple) × multiple
```

默认：

```text
16:9
1.2 MP
multiple 32
→ 1504 × 832
```

实际宽高结果是普通信息，不用橙色抢焦点。

---

## 9.2 二次潜空间放大（v0.6.12 补充）

v0.6.12 增加的这项设置在 v0.6.13 中移入右下生成参数区。参数内容先显示比例、MP、尺寸倍数和最终宽高，再显示 **二次潜空间放大 · 项目共用**。

生成按钮位于该区域独立固定底栏；预览开关位于上方预览标题右侧，不放入参数滚动区。字段、默认值与保存语义保持不变。

默认关闭；开启后展开放大模型和高清阶段步数。关闭只停用设置，保留已填写的模型与步数。开关开启状态沿用紫色，普通参数和尺寸说明保持中性，主生成按钮仍为橙色。

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 二次潜空间放大 | 关闭 | 作用于本项目的生成配置；切换片段不切换该设置 |
| 放大模型 | 自动选择，保存空字符串 | 真实接入时选择兼容 H3 的模型；当前不扫描本地模型 |
| 高清阶段步数 | 4 | 必须为正整数；真实接入时须小于工作流实际总步数 |

模型名称 `minimax_h3_latent_upscaler_3d_bf16.safetensors` 只作为明确标注的示例，不能表示已发现、已安装或已验证该模型。自动选择也只是当前保存的配置语义，不表示 Demo 已连接后端。

当前尚未接入工作流总步数，因此只校验高清阶段步数为正整数，不设基于假定总步数的硬上限。界面用以下例子解释两个阶段：

> 例如工作流总计 8 步、高清阶段 4 步时：4 步低清 + 4 步高清。

示例中的 8 不进入项目状态或导出配置。真实接入后，按工作流实际采样步数校验，保证低清和高清阶段各至少有一步。

### 分辨率语义

原有分辨率控件继续表示**最终目标尺寸**。低清阶段约为目标的半宽半高，再按模型网格对齐；完成潜空间放大后回到设定的输出尺寸。不新增倍率控件，不把已有宽高再乘以 2，也不将简单除以 2 的数值当成实际低清尺寸。

### 项目状态与操作

项目内保存一份配置：

```js
state.latentUpscale = {
  enabled: false,
  model: '',
  highSteps: 4
};
```

- 开关和参数修改支持撤销 / 重做。
- 切换时间线片段保留同一项目值；没有片段的空项目也可设置。
- 新建项目与重置 Demo 均恢复上述默认值。
- 导出格式版本为 9，写入 `project.latentUpscale`；不为每个片段复制放大配置。
- 当前仅完成 UI 配置与演示，不执行真实生成、潜空间放大或模型目录扫描。

参考固定提交 `a81f13b8af4a162467cec4dc377f40b7354d7ffc` 的 [`minimax_h3_finite_segments.py` / `_selflift_settings`](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector/blob/a81f13b8af4a162467cec4dc377f40b7354d7ffc/minimax_h3_finite_segments.py#L43-L91)。真实接入时，项目配置对应参考 timeline 顶层的 `secondPass`、`secondPassModel`、`secondPassHighSteps`，并使用工作流实际总步数进行校验。

## 9.3 生成动作

预览开关位于预览标题右侧，开启时为二级紫色状态。

主生成按钮：

> **最高优先级橙色**

这是右侧操作区最醒目的动作。按钮放在右下参数区独立固定底栏，参数内容在其上方滚动；展开设置、滚动参数或调整分隔线都不能把按钮卷走。窄屏排列同样保持参数滚动区与动作底栏分离，不将生成按钮夹在参数内容中。“固定”指按钮留在参数区域底栏；滚动整个窄屏页面时，按钮随所属区域移动，不悬浮在视口上。

# 13. 片段承接规则

片段承接由时间位置自动推导，用户不需要重复配置同一关系。

## 13.1 首尾吸附：可切换镜头关系

当相邻两个时间线片段满足：

```text
当前片段.startFrame === 上一片段.endFrame
```

即 **零空隙、零重叠、首尾吸附** 时，时间线接缝气泡显示当前镜头关系，并在文字右侧增加一个很小的下拉箭头。

可选三种模式：

- **尾帧参考**：默认。取上一片段最终可见尾帧作为当前片段额外的 H3 图片参考，只用于继承人物 / 场景状态、色彩、光线和整体基调；当前片段仍按自己的 Prompt 重新构图和运镜。
- **尾帧续接**：取上一片段最终可见尾帧作为当前片段 frame 0 Guide，用于无缝连续 / 一镜到底式镜头。
- **独立**：时间上仍首尾贴合，但生成时完全不读取上一片段。

UI 仍保持原接缝气泡大小和位置，不增加新的常驻面板。当前文字例如：

```text
尾帧参考⌄
尾帧续接⌄
独立⌄
```

模式保存在 **后一个片段** 的 `transitionMode`，因为它描述的是“当前片段如何使用上一片段”。

由于内部时间范围是半开区间 `[startFrame, endFrame)`，上一片段的视觉尾帧是：

```text
previous.endFrame - 1
```

### 用户默认偏好

ComfyUI Settings 中注册：

```text
TerryDirector
└─ 时间线
   └─ 默认镜头衔接
      ├─ 尾帧参考
      ├─ 尾帧续接
      └─ 独立
```

产品默认值为 **尾帧参考**。

这个设置只决定之后新建片段的默认 `transitionMode`，修改 Settings 不批量修改已有时间线。

已有旧工作流没有 `transitionMode` 字段时，继续按 **尾帧续接** 解释，保证此前已验证的一镜到底工作流行为不变化。

### 自动尾帧不是项目资产

无论尾帧参考还是尾帧续接，自动取出的上一镜头尾帧：

- 不加入项目资产池
- 不占用项目级稳定 `Picture N` 编号
- 不显示为可删除的普通参考资产卡片
- 不需要用户再次选择图片

其中尾帧参考在**单个 H3 执行任务内部**占用一个图片参考位，因此该片段最多再引用 8 张普通图片。

### 时间几何优先级

```text
有空隙       → 独立生成
首尾恰好吸附 → 使用 transitionMode
产生重叠     → 使用 overlap 连续性机制
```

因此拖开或拖成重叠时，保存的 `transitionMode` 不删除，只是在当前几何关系下暂时不生效；再次首尾贴合时恢复使用。

### 上一片段尚未生成

当当前模式为尾帧参考或尾帧续接，但上一片段尚无可用输出：

- 不伪造尾帧
- 当前片段生成任务依赖上一片段先完成
- Queue / Compiler 层负责建立生成依赖
- UI 可以显示等待依赖状态，但不增加新的常驻配置面板

# 14. 后续联动

时间线锁链按钮：

> **后续联动**

默认开启。

---

## 14.1 移动

开启时拖动片段 N：

```text
片段 N      跟随
片段 N+1    跟随
片段 N+2    跟随
...
```

前面的片段不动。

整组：

- 同距移动
- 内部片段时长不变
- 内部间距不变
- 内部重叠不变

---

## 14.2 尾部调整

开启后续联动时调整当前片段尾部：

```text
当前片段 endFrame += Δ
后续所有片段 start/end += Δ
```

结果：

- 当前片段起点不变
- 与下一片段原有间距 / 重叠不变
- 后续片段自身时长不变

关闭联动后：

> 只调整当前片段尾部。

---

## 14.3 头部调整

片段头部 Trim：

> 始终只调整当前片段。

不触发后续联动。

---

## 14.4 Undo

一次拖动或裁剪：

> 一次 Undo。

Esc：

> 取消整次操作，所有联动片段一起恢复。

吸附时不能把正在联动移动的片段自身旧边缘作为吸附目标。

后续联动是工具状态，不保存进项目数据。

# 17. 响应式

桌面优先。

| 视口 | 区域排列 |
| --- | --- |
| 桌面，视口宽度大于 900px | 左侧全高提示词；右侧上排左预览、右资产池，下排集中参数与固定动作底栏；时间线在底部跨全宽 |
| 窄屏，视口宽度不超过 900px | 提示词、生成预览、资产池、生成参数、时间线依次堆叠；资产池固定 280px、参数面板固定 360px，均内部滚动；生成动作底栏仍在参数滚动区外，按钮在参数区内全宽显示 |

可拖分隔线只在相应方向存在并排区域时生效；窄屏不增加字段，不改变分辨率、项目配置或导出含义。视口宽度不超过 760px 时，沿用时间线 40px 工具栏空间补偿。

窄屏生成动作固定在参数区域内部；滚动整个页面时随该区域移动，不作为悬浮视口控件。

要求：

- 不出现页面级横向溢出
- 工作台外壳留白保留
- 菜单始终落在视口内
- 生成预览不能覆盖其他区域
- 参数滚动不带走主生成动作，预览开关仍在预览标题右侧
- 时间线工具不足一行时允许工具区域滚动 / 换行，但总编排时长保持可读
- 不通过删除按钮文字解决空间不足

# 19. 正式功能接入点

UI 蓝图冻结后，真实功能应从现有界面向后接，而不是先重构前端。

| UI | 正式能力 |
| --- | --- |
| 项目入口 | 项目创建 / 打开 / 保存 |
| 上传资产 | 写入 ComfyUI input，并注册到项目资产池 |
| 从 ComfyUI input 选取 | 服务端目录枚举、搜索、媒体元数据 |
| 资产灯箱 | 读取真实图片 / 视频 / 音频 |
| Prompt 编辑器 | 保存真实片段 Prompt |
| 时间线 | 保存 startFrame / endFrame |
| 首尾吸附 | 自动取上一片段输出尾帧作为当前片段边界参考 |
| 重叠 | 编译成 overlap / latent continuity 输入 |
| 参考引用 | 编译成当前片段 Generation IR |
| 分辨率 | 写入真实生成参数 |
| 二次潜空间放大 | 项目共用配置映射到参考节点二采参数；按真实工作流总步数校验 |

| 生成进度 | 读取真实 Queue / Execution 状态 |
| 生成预览 | 接 ComfyUI latent preview |
| 片段底部状态 | 显示真实耗时 / 完成状态 |
| 导出配置 | 导出真实项目配置 |

实现时优先薄接入，不增加“为了严谨”的额外页面或抽象层。

# 21. 实现红线

1. **不要为了接后端重排已经确认的 UI。**
2. 不把生成预览重新做成页面中心。
3. 不把资产池降级成“当前片段参考列表”。
4. 不把重叠变成独立可编辑对象。
5. 不把首尾吸附的尾帧续接做成手工资产引用。
6. 不恢复未选中片段 Hover 白色 Trim Handle。
7. 不移除按钮文字只留图标。
8. 不重新加入 AI 增强和版本管理占位入口。
9. 不让实现层的 Workflow 节点 ID、路径或模型字段直接污染 UI 数据模型。
10. 不为未来假设需求增加复杂架构。
11. Demo 中已经确认的尺寸、颜色和交互，除非用户再次明确修改，否则视为实现验收基线。

# 23. 冻结结论

从 **Demo v0.6.11** 开始，TerryDirector 的 UI 设计阶段进入冻结状态。

**Demo v0.6.12** 补入用户确认的项目共用二次潜空间放大设置。

**Demo v0.6.13** 按用户新示意图调整工作区：左侧全高提示词，右上左预览 / 右资产池，右下集中参数；预览开关移到标题右侧，生成动作位于独立固定底栏。该补充覆盖早期三列和资产默认 680px 规则。其他视觉与交互继续遵循蓝图 1.0 基线，项目配置和导出版本 9 保持不变。

后续工作重点从：

> “界面应该长什么样”

切换到：

> “如何让这套界面真正驱动 ComfyUI 完成项目、资产、提示词、时间线和生成任务”。

除非出现真实使用问题或用户再次明确提出视觉改动，否则功能实现阶段应以本蓝图作为前端验收标准。
