# H3 提示词编辑器移植记录

本轮仅移植用户指定编辑器中**正在使用的菜单、语法与标签交互**，不搬 ComfyUI 节点注册、总线、连线解析或运行环境。

来源仓库：`terry-xu-2077/ComfyUI-TerryXu-nodes`

固定来源版本：`97263bca7ca1e40348a273244e5feebb9877126b`

- `web/h3_shared_menus.js`：`buildAssetMenu`、`commands`、`categoryOptions`、`handleCommandKey`、`openH3AssetMenuForChip`。
- `web/h3_rich_text.js`：`H3_CAMERA_COMMANDS`、标签识别与中英显示、对白语言、原文序列化、可点击标签和原子删除。
- `web/h3_prompt_editor.js`：两种显示模式共用同一原文、菜单绑定方式。

## 菜单对应

| 来源行为 | TerryDirector 实现 |
| --- | --- |
| `@` 引用参考 | 项目资产池的图片、视频、音频；图片缩略图、名称、稳定项目编号；关键词筛选 |
| 点击已有媒体标签 | 同一引用菜单更换素材，原文保留 `<Picture n>` / `<Video n>` / `<Audio n>` |
| `/` 一级分类 | 结构、镜头、对白、保留关系、任务类型 |
| 结构 | 原样保留 7 项；`non_diegetic_music:` 后另起一行 `N/A` |
| 镜头 | 下一个 `[Shot n]`、`[00:00]`、下一个 `(Sn)`；镜头运动为下一级菜单 |
| 运镜 | 全部 20 项；中文显示与英文 H3 句子保持对应 |
| 对白 | `<d>[Chinese] </d>`、`<scenetrans>`、`<cutoff>`；对白内容可编辑，20 种语言可选 |
| 保留关系 | 原样保留 7 项 |
| 任务类型 | 原样保留 6 项 |
| 键盘 | ↑↓ 选择；→ / Enter / Tab 进入或插入；← 返回上级；Esc 关闭 |
| 关键词 | 命令名、中文分类、中文描述、原始语法均可检索 |
| 点击标签 | 镜头编号、说话人编号、时间戳、运镜均可修改 |

共 46 条命令，原始语法值保存在 `src/h3-syntax.js`，不替换成模型无法识别的中文字符串。原来源当前的 `@` 是参考素材列表；代码中未接入该列表的历史 Subject 来源管理工具不扩张为新的面板。

## 接入方式

`src/h3-editor.js` 为静态页面的薄适配：用项目资产池代替 ComfyUI 图连接查询，选取后只修改当前片段，用现有项目撤销记录代替 ComfyUI 图变更通知。保持原生 JavaScript，不安装富文本框架。

可视化与纯文本只有一份 `prompt`。标签以 `data-raw` 保留完整 H3 语法；复制 / 剪切输出原文，粘贴只读取纯文本并重新识别标签。普通输入不重建整个工作区；组合输入期间不替换输入节点。

纯文本模式也可使用相同的 `@` 和 `/` 菜单，插入纯文本；可视化模式插入可交互标签。素材栏的“插入引用”在当前模式和光标处插入，不强制跳回纯文本。

## 检查

Node 检查覆盖目录数量、原始运镜语句、动态编号、特殊字段换行和标签识别；23 项既有时间线 / 帧运算检查保留。

Chromium 内联页面操作检查覆盖：固定预览、不遮挡编辑区、46 条语法的序列化往返、全选复制、层级菜单与搜索、引用插入及更换、原子删除及撤销、多行编辑、对白 / 语言 / 时间 / 运镜编辑、纯文本菜单、组合输入事件、素材灯箱、生成预览开关及运行片段绑定、片段切换与窄屏菜单避让。

组合输入检查使用浏览器 CompositionEvent 模拟，不等同于已验证用户电脑上的所有中文输入法。环境禁止 `file://` 导航，浏览器检查使用相同源码的内联页面；不宣称已验证线上 Pages 或真实模型生成。

## v0.6.6 资产源语义修正

按照用户确认的共用资产池，`@` 与媒体标签更换读取全项目素材，而不是先绑定才可见。菜单分类、46 条语法和运镜交互不变。绑定关系由提示词内的稳定项目标签映射到资产 ID；更换和删除标签只更新所在片段。菜单空状态文案同步为“项目资产池暂无…”。
