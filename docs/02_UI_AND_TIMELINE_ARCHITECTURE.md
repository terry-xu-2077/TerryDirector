# TerryDirector UI 与时间线架构

> 当前基线：Demo v0.6.2。左侧提示词、中间参考资产、右侧固定生成预览。
> 保持 HTML / CSS / JavaScript、根目录 index.html 和相对资源路径，不拆 React、不加运行依赖。

## 1. 工作台用途

编排镜头生成任务，不是通用剪辑软件。主流程：时间线选片段 → 写提示词 → 填参考资产 → 生成。只实现用户明确需要的功能，不补未经确认的管理面板、版本系统或 AI 增强。

## 2. 布局

```text
顶部：项目入口 / 项目名 / 操作说明 / 导出
┌──────────────────────────┬──────────────────┬───────────────────┐
│ 提示词编辑               │ 参考资产配置     │ 生成预览          │
│                          │                  │ 固定布局，可隐藏  │
│ 可视化 / 纯文本          │ 从项目选取 / 导入│ 中间画面 / 当前任务│
│ @ 引用 / / H3 语法       │ 缩略图 / 插入引用│                   │
│                          │                  │                   │
│ 预览开关 / 分辨率 / 生成 │                  │                   │
├──────────────────────────┴──────────────────┴───────────────────┤
│ 单行时间线：新建 / 选择 / 移动 / 裁剪 / 重叠反馈                   │
└────────────────────────────────────────────────────────────────┘
```

参考资产独立成中间一列，位于提示词与生成预览之间，不再堆在预览下面。提示词仍占主要编辑空间。生成预览在最右侧正常布局中，**不是浮窗，也不覆盖其他区域**。

默认显示预览；隐藏后其空间交给资产区，提示词宽度保持稳定。提示词与资产之间原有的分隔线仍可调整宽度，时间线仍可拖动调整高度，双击分隔线恢复当前紧凑默认值。窄屏按“提示词 → 参考资产 → 生成预览”上下排列；不添加新面板或布局框架。

浏览器四周的留白在上一版基础上加倍：`clamp(24px, 6vmin, 80px)`，例如 1440×900 窗口从 27px 增为 54px。只压暗应用外侧的灰蓝背景，内部完整灰蓝紫配色、细亮边及外壳阴影保留，不恢复贴边全屏布局。

提示词顶部保持两行但压缩空隙：片段标题行 44px，提示词工具行 28px，编辑框上方间距 6px，总计从 132px 降为 78px。不缩小正文或隐藏模式切换、`@`、`/` 提示。

## 3. 可编辑提示词

每片段只有一份 `prompt`，可视化 / 纯文本只是两种显示。默认可视化，**可直接输入、换行、删除、选中、复制、剪切、粘贴**。

按用户指定的 H3 编辑器移植：

- `@`：当前片段已填充的图片、视频、音频，含名称、图片缩略图与编号；支持筛选及键盘确认；点击已有引用标签可更换。
- `/`：结构、镜头、对白、保留关系、任务类型五类；镜头下包含镜头运动子菜单，保留全部 20 种运镜及来源的原始 H3 语句。
- 菜单支持方向键、Enter、Tab、Esc、返回上级与关键词检索。
- 镜头、说话人、时间戳、运镜标签可点击修改。对白块可编辑内容及语言。
- `non_diegetic_music:` 默认下一行填入 `N/A`。

界面标签可显示中文，但存储、纯文本、剪贴板和导出保留原始 H3 语法。一次复制不能漏掉格式化标签；切换片段和显示方式不能丢换行或引用。

输入过程只更新当前提示词，不重建工作区或时间线；组合输入期间不替换输入节点。编辑器使用现有撤销记录，不另建项目状态。编辑焦点内不触发时间线的删除、平移等快捷键。

移植对应与来源版本见 [H3_EDITOR_PORT](H3_EDITOR_PORT.md)。

## 4. 参考资产与大图

参考区域只显示当前片段绑定资产。外部拖入 / 导入后绑定当前片段；“从项目选取”按需弹出。图片、视频、音频分别从 1 编号。

点击素材主体打开独立大图 / 媒体灯箱，**不嵌入生成预览区域**。关闭或退出灯箱停止并释放媒体。素材栏“插入引用”为独立按钮，在当前编辑模式的光标处写入标签；“移除”只解绑并更新当前提示词的引用编号，不删除素材。

## 5. 生成预览

生成预览专门显示生成过程的反馈，与素材灯箱分离，不跟随播放头。预览绑定正在运行的任务；切换编辑片段不把别的参考图显示成该任务输出。任务结束可保留最后一次反馈，不新增版本浏览。

本 Demo 没有真实采样数据：未运行时显示等待，不拿参考图冒充生成结果；模拟运行时，捕获的参考静帧仅作模糊变化的交互占位，始终标明“演示 · 非模型输出”。关闭时不挂载预览图片，模拟进度仍可继续。

正式接入时优先复用 ComfyUI 原生采样预览，接口与实际 H3 环境另行验证。此次不添加连接层或视频生成后端。

## 6. 时间线

时间线默认高度从 248px 降为 200px；拖动范围为 200–400px，双击复位到 200px。工具栏 38px、底部滚动条区域 18px，Canvas 最小高度 144px。紧凑状态的片段高 54px，仍保留标题、进度 / 耗时、框下 18px 引线间隔和完整时长气泡；不能为压缩高度裁掉标记。

保持已认可的单行时间线，不重写引擎。后片段在交集处叠放于前片段之上；拖本体移动、拖边缘裁剪。白色把手只为选中片段显示，未选中悬停不显示白条。

唯一时间事实为整数帧半开区间 `[start,end)`。重叠由交集自动派生，不可单独选中或拖动；时长标记必须用引线放在框下方。片段底部保留模拟进度和生成耗时，活动状态不随编辑撤销回退。

所有操作按钮使用图标加可见名称；“新建片段”在左侧。保留吸附、平移、缩放、一步拖动撤销。最多两个相邻片段重叠，不添加额外轨道。

## 7. 数据与范围

项目首页保留已有文件夹视觉，不常驻占用工作区。片段只保存单份提示词与已有属性，菜单、光标、灯箱、预览开关为临时界面状态。

颜色通过完整主题色板和语义变量管理，不限制五个颜色，不新增主题设置。Demo 刷新还原，导出不含媒体文件。无 React、AI 增强、片段版本、模型调用或后端持久化；不修改共享 UI 库、Rulesmd Editor 或参考节点仓库。

当前范围以本文为准，早期产品探索文档中的能力不等于当前已实现功能。
