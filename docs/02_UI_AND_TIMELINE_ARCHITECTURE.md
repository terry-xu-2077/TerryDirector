# TerryDirector UI 与时间线架构

> 当前基线：Demo v0.6.8。左侧提示词、中间项目资产池、右侧固定生成预览。
> 保持 HTML / CSS / JavaScript、根目录 index.html 和相对资源路径，不拆 React、不加运行依赖。

## 1. 工作台用途

编排镜头生成任务，不是通用剪辑软件。主流程：时间线选片段 → 写提示词 → 填参考资产 → 生成。只实现用户明确需要的功能，不补未经确认的管理面板、版本系统或 AI 增强。

## 2. 布局

```text
顶部：项目入口 / 项目名 / 操作说明 / 导出
┌──────────────────────────┬──────────────────┬───────────────────┐
│ 提示词编辑               │ 参考资产配置     │ 生成预览          │
│                          │                  │ 固定布局，仅开关  │
│ 可视化 / 纯文本          │ 项目共用 / 导入  │ 中间画面 / 当前任务│
│ @ 引用 / / H3 语法       │ 缩略图 / 插入引用│                   │
│                          │                  │                   │
│ 编辑提示 / 字数          │                  │ 分辨率 / 开关 / 生成│
├──────────────────────────┴──────────────────┴───────────────────┤
│ 单行时间线：新建 / 选择 / 移动 / 裁剪 / 重叠反馈                   │
└────────────────────────────────────────────────────────────────┘
```

参考资产默认宽度设为 680px，采用用户截图手动调宽后的布局；较窄视口仍按原有空间约束收窄，不挤掉提示词或预览。分隔线继续可调，双击恢复这套默认宽度。参考资产独立成中间一列，位于提示词与生成预览之间，不再堆在预览下面。提示词仍占主要编辑空间。生成预览在最右侧正常布局中，**不是浮窗，也不覆盖其他区域**。

预览窗始终占据固定区域，默认开启。关闭只停止显示 / 更新画面，显示“生成预览已关闭”，不会隐藏窗口、回收列宽或移动其他区域。任务进度继续更新，分辨率和生成操作仍可使用。提示词与资产之间原有的分隔线仍可调整宽度，时间线仍可拖动调整高度，双击分隔线恢复当前紧凑默认值。窄屏按“提示词 → 参考资产 → 生成预览”上下排列；不添加新面板或布局框架。

浏览器四周的留白在上一版基础上加倍：`clamp(24px, 6vmin, 80px)`，例如 1440×900 窗口从 27px 增为 54px。只压暗应用外侧的灰蓝背景，内部完整灰蓝紫配色、细亮边及外壳阴影保留，不恢复贴边全屏布局。

提示词顶部保持两行但压缩空隙：片段标题行 44px，提示词工具行 28px，编辑框上方间距 6px，总计从 132px 降为 78px。不缩小正文或隐藏模式切换、`@`、`/` 提示。

## 3. 可编辑提示词

行内标签统一采用 28px 最小高度、20px 内容行高与 `vertical-align: middle`；素材缩略图 20×20。图片、音视频、语法和对白块的中心对齐，多行对白可自然增高，不用像素偏移补丁或修改原文来调位置。

每片段只有一份 `prompt`，可视化 / 纯文本只是两种显示。默认可视化，**可直接输入、换行、删除、选中、复制、剪切、粘贴**。

按用户指定的 H3 编辑器移植：

- `@`：整个项目资产池的图片、视频、音频，含名称、图片缩略图与编号；支持筛选及键盘确认；点击已有引用标签可更换。
- `/`：结构、镜头、对白、保留关系、任务类型五类；镜头下包含镜头运动子菜单，保留全部 20 种运镜及来源的原始 H3 语句。
- 菜单支持方向键、Enter、Tab、Esc、返回上级与关键词检索。
- 镜头、说话人、时间戳、运镜标签可点击修改。对白块可编辑内容及语言。
- `non_diegetic_music:` 默认下一行填入 `N/A`。

界面标签可显示中文，但存储、纯文本、剪贴板和导出保留原始 H3 语法。一次复制不能漏掉格式化标签；切换片段和显示方式不能丢换行或引用。

输入过程只更新当前提示词，不重建工作区或时间线；组合输入期间不替换输入节点。编辑器使用现有撤销记录，不另建项目状态。编辑焦点内不触发时间线的删除、平移等快捷键。

移植对应与来源版本见 [H3_EDITOR_PORT](H3_EDITOR_PORT.md)。

## 4. 项目共用资产池与大图

**资产属于项目，片段只引用资产。** 中间列显示项目全部图片、视频、音频，不按当前片段过滤。切换片段保持原网格和滚动位置，只更新“当前引用”的轻量标记。不是跨项目共享目录，也不新增全局资源管理系统。

保留用户调定的默认 680px 列宽、四格一行、52px 缩略图；移除重复的添加格。大图灯箱、按钮文字、分隔线与其他区域比例不变。

顶部只有两个语义不同的入口，不再放重复的“添加素材”格子：

- **上传资产**：选择用户设备上的新文件，正式版上传到 ComfyUI 管理的 input 后加入项目资产池；Demo 只生成本页媒体引用，明确文件尚未上传。
- **从 ComfyUI input 选取**：浏览 ComfyUI 运行端 input 的已有素材（包括子目录），选取后加入项目资产池，不重新上传或复制文件。这不是已经显示的项目资产池的另一份列表。

Demo 使用明确标注的示例目录展示第二个入口，支持文件名 / 子目录搜索、多选、已入池标记、确认 / 取消。同一 input 相对路径不重复入池，不因选择而修改片段提示词；可一步撤销整次加入。删除池引用不删除 input 原文件。示例来源记录为 `demo-input`，不导出成真实服务器路径。

两个入口与外部拖入都只加入池，不自动修改任何片段。没有片段时也可先添加资产；“插入引用”在没有目标片段时禁用。真正的服务端目录列举、上传和媒体读取留到 ComfyUI 插件阶段，不为 Demo 添加后端或扫描用户本地路径。

引用有三个入口：点击素材下方“插入引用”、在提示词输入 `@`、从资产池拖到时间线片段。前两种写入当前片段的光标位置；拖拽写入目标片段提示词。引用既有素材不复制媒体。向时间线片段直接拖入外部文件时，同时加入池并引用到目标片段，作为一次可撤销操作。

### 编号与引用

- 图片、视频、音频分别使用稳定的项目编号，如 `Picture 1`、`Picture 2`、`Audio 1`。导入分配一次，切换片段和删除别的素材不重排；删除后的编号不立即复用。
- 可视化、纯文本、`@` 菜单、池内标签使用同一对应关系。不能让同一个 `Picture 2` 在不同片段中暗指不同素材。
- 每片段的 `refs` 是从该片段提示词解析出的资产 ID 列表，重复引用只统计一次。编辑 / 替换 / 删除标签时更新当前片段关系，不把全部池素材附进每个任务。
- 当前只导出项目配置：格式版本 8 包含项目资产表、稳定标签与各片段引用；明确 `referenceNumbering: project-stable`。未来提交真实生成任务时，再由编译层将实际引用映射到模型所需的局部编号。此轮不添加生成编译后端。

### 删除与查看

在提示词中删除某素材的标签，只取消那个片段的引用，其他片段和资产池不变。资产池的“删除”是项目级操作：确认窗提示受影响片段，确认后移除素材及所有片段中对应的标签；一次撤销同时恢复素材和标签。不删除磁盘原文件。

媒体对象只保存一份；历史记录保存项目有效资产 ID。被删除的本地 Object URL 在页面会话中暂留以支持撤销，不因单个片段切换而释放；新建项目 / 重置会清理旧项目的媒体，当前新建项目不继承旧资产池。

点击素材主体仅打开独立大图 / 音视频灯箱，不建立引用，不占用生成预览窗。关闭灯箱停止播放。所有本地文件仍不上传，刷新仍还原 Demo。

## 5. 生成预览

生成预览专门显示生成过程的反馈，与素材灯箱分离，不跟随播放头。预览绑定正在运行的任务；切换编辑片段不把别的参考图显示成该任务输出。任务结束可保留最后一次反馈，不新增版本浏览。

本 Demo 没有真实采样数据：未运行时显示等待，不拿参考图冒充生成结果；模拟运行时，捕获的参考静帧仅作模糊变化的交互占位，始终标明“演示 · 非模型输出”。关闭时清除预览图片来源及视觉效果，但保留预览框与任务状态；模拟进度仍可继续。重新开启后显示同一任务的最新反馈，不重新提交任务。

正式接入时优先复用 ComfyUI 原生采样预览，接口与实际 H3 环境另行验证。此次不添加连接层或视频生成后端。

## 6. 时间线

时间线默认高度从 248px 降为 200px；拖动范围为 200–400px，双击复位到 200px。工具栏 38px、底部滚动条区域 18px，Canvas 最小高度 144px。紧凑状态的片段高 54px，仍保留标题、进度 / 耗时、框下 18px 引线间隔和完整时长气泡；不能为压缩高度裁掉标记。

保持已认可的单行时间线，不重写引擎。后片段在交集处叠放于前片段之上；拖本体移动、拖边缘裁剪。白色把手只为选中片段显示，未选中悬停不显示白条。

唯一时间事实为整数帧半开区间 `[start,end)`。重叠由交集自动派生，不可单独选中或拖动；时长标记必须用引线放在框下方。片段底部保留模拟进度和生成耗时，活动状态不随编辑撤销回退。

所有操作按钮使用图标加可见名称；“新建片段”在左侧。保留吸附、平移、缩放、一步拖动撤销。最多两个相邻片段重叠，不添加额外轨道。

### 后续联动

时间线工具栏在吸附旁增加锁链图标 + **后续联动** 文字开关，默认开启；高亮和 `aria-pressed` 同步表达开关状态。

- 开启：拖动片段本体时，以被拖动的片段为头，它后面的所有片段同距平移，包括中间有空隙的片段。前面的片段保持不动；组内时长、间距、重叠不变。
- 关闭：沿用单片段移动，不移动后续片段。边缘裁剪在两种状态下均保持原行为，不联动。
- 片段 1 移动可带动全链；中间片段只带动后缀；末片段等价于单独移动。这里只是当前移动操作的范围，不建立永久绑定组。
- 拖拽开始时固定联动范围；从原始位置计算统一帧偏移。吸附排除所有正在移动片段的旧边缘，仍对齐零点、播放头和固定前方片段。
- 向左移动保留零点、顺序与最多两片段重叠约束；达到边界时整组一起停止，不分别夹紧导致相对关系改变。向右不再被一起移动的后续片段旧位置挡住。
- 一次拖动作为一次撤销；Esc / 指针取消恢复整组。进度与资产、提示词、分辨率不受影响。
- 开关是页面临时工具状态，不写入项目配置，不产生撤销项。Demo 重置恢复开启。

## 7. 分辨率选择

取消固定 720P / 1080P 下拉。预览窗下方放置紧凑控件：**画面比例、像素量 MP、尺寸倍数、实际宽 × 高**，不增加参数侧栏。输出标签为只读计算结果。下方依次放置“生成预览”开关和生成按钮，提示词底部仅保留编辑提示与字数；不增加设置面板。

- 比例沿用 Resolution Selector 的八项：1:1、2:3、3:2、3:4、4:3、9:16、16:9、21:9。
- 像素量可直接输入 0.1–16 MP，输入步长 0.01，支持参考图中的 0.98。
- 倍数范围 8–128，步长 4；默认 32。它表示宽高对齐步长，不是把原尺寸放大 32 倍。
- 默认 16:9 / 1.2 MP / 32，实时显示 1504 × 832。参考图的 14 行都使用同一公式算出，不写死尺寸表。
- 修改只更新当前片段及计算标签，不重建提示词编辑器；支持撤销、复制片段和切换片段。无效或未输完的数字不写入项目，暂时禁用生成，不能产生 NaN 或静默改成其他规格。

计算与官方源码一致：

```text
总像素 = megapixels × 1024 × 1024
scale = sqrt(总像素 / (比例宽 × 比例高))
width  = round_even(比例宽 × scale / multiple) × multiple
height = round_even(比例高 × scale / multiple) × multiple
```

原节点 Python 的 `round` 使用中点取偶；本 Demo 保持一致。像素取整后实际比例和总像素可能与输入略有差异，以宽高标签为准。每片段保存 `{aspect_ratio, megapixels, multiple}`；导出时由同一函数附上 `width`、`height`，导出格式版本为 8（同时保存项目稳定素材编号）。

来源：[ComfyUI nodes_resolution.py](https://github.com/Comfy-Org/ComfyUI/blob/491bf3b928db565328292f83268d00af57867786/comfy_extras/nodes_resolution.py)。此处只移植尺寸计算，不引入 ComfyUI 或新依赖，也不声称任意模型都接受全部规格。

## 8. 数据与范围

项目首页保留已有文件夹视觉，不常驻占用工作区。片段只保存单份提示词与已有属性，菜单、光标、灯箱、预览开关为临时界面状态。

颜色通过完整主题色板和语义变量管理，不限制五个颜色，不新增主题设置。Demo 刷新还原，导出不含媒体文件。无 React、AI 增强、片段版本、模型调用或后端持久化；不修改共享 UI 库、Rulesmd Editor 或参考节点仓库。

当前范围以本文为准，早期产品探索文档中的能力不等于当前已实现功能。
