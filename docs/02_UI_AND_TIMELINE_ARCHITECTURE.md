# TerryDirector UI 与时间线架构

> 当前基线：Demo v0.4。任务编排为主，参考预览可关闭；提示词取消 AI 增强。
> 继续使用 HTML / CSS / JavaScript，保留根目录 index.html，不拆 React 架构。

## 1. 功能边界

**编排镜头生成任务，不是实时视频剪辑工作台。**

基本流程：时间线上选片段 → 写提示词 → 填参考资产 → 生成。

参考 ComfyUI-MiniMaxH3-TimelineDirector 的实用思路，但只实现用户确认的需求。不因“专业软件应该有”增加检查器、版本栏、素材管理侧栏或其他占位面板。当前不做片段版本管理或 AI 提示词增强。

## 2. 三个常驻区域与可选预览

```text
顶部：项目入口 / 项目名称 / 操作说明 / 导出配置

┌──────────────────────────────────┬───────────────────┐
│                                  │ 参考资产  显示预览 │
│          提示词编辑              │ 从项目选取 / 导入 │
│                                  │ ┌───────────────┐ │
│      可视化 / 纯文本             │ │按需参考预览   │ │
│                                  │ │默认关闭       │ │
│                                  │ └───────────────┘ │
│                   模拟生成       │ 当前片段绑定资产  │
├──────────────────────────────────┴───────────────────┤
│ 时间线  新建片段  撤销 / 重做 / 选择 / 平移 / 吸附…    │
│                 单行时间线                            │
│ 片段选择 / 移动 / 裁剪 / 自动重叠 / 进度与耗时          │
└───────────────────────────────────────────────────────┘
```

预览在现有资产区内部展开，不新增常驻工作区，不改变提示词区域宽度。不恢复大监视器、左侧片段卡片列表或右侧整列设置。时间线本身就是片段选择入口。

提示词和资产之间的分隔线、时间线高度可以拖动。窄屏仍能访问资产区，工具栏可横向滚动，不能通过去掉按钮文字来强行挤下所有按钮。

## 3. 提示词

每片段只保留一个 `prompt` 字符串。UI 只有 **可视化 / 纯文本** 两种显示方式，两种方式读取同一份内容。移除 AI 增强页签、增强按钮、示例增强逻辑和提示词来源字段，配置导出也不再携带双份提示词。

默认纯文本编辑。可视化当前为标签格式化的只读展示，不冒充完整富文本编辑器。切换方式或片段不能丢字、丢引用标签。拖播放头只定位时间，不切换正在编辑的片段。

片段名称可在编辑区顶部修改，时长与重叠值只作只读摘要，位置和时长直接在时间线上操作。生成按钮位于提示词区底部，分辨率为旁边的紧凑控件，不增加参数墙。

## 4. 参考资产填充

资产区只显示当前片段已绑定的图片、视频、音频；项目素材库通过“从项目选取”临时弹窗打开。拖入本地文件或点击导入后立即绑定当前片段，不上传文件。

点击资产主体仍在提示词光标处插入引用。资产下方“预览”“移除”是独立文字按钮：预览不能插入标签，移除只解绑并更新当前提示词中受影响的编号，不删除项目素材或本地文件。参考资产可以拖到其他时间线片段上复用。

图片、视频、音频分别编号。本地文件只通过当前页面 Object URL 使用，刷新需重新导入。

## 5. 预览开关

- 资产区右上角“显示预览 / 关闭预览”，默认关闭；也可从某资产的“预览”直接打开。
- 预览当前片段的参考素材，切换片段时跟随其绑定资产。片段无参考或项目为空时显示简单提示。
- 图片按原比例显示；视频、音频使用浏览器原生播放控件，不自动播放。不增加全片联播、视频拼接、时间线同步播放器或版本比较。
- 标明“参考素材 / 非生成结果”。模拟生成没有真实视频，不把参考图伪装成生成结果。
- 关闭预览清除媒体元素；切换片段、换预览资产、解绑当前素材或返回项目首页时，停止旧媒体并释放其播放源。
- 同一素材预览期间，编辑提示词或名称不能重建播放器、打断播放。返回页面可恢复预览内容，但不自动播放。
- 预览开关属于页面临时状态，不进入项目、撤销记录或导出配置。关闭状态不加载预览媒体。
- 不支持的本地格式显示失败提示，不阻止素材继续作为参考使用。当前不转码、不做代理缓存。

## 6. 工具栏

时间线操作采用 **图标 + 可见文字**，不只提供图标或悬停提示。包括撤销、重做、选择、平移、吸附、复制、删除、缩小、放大、适应全部。

**新建片段在左侧，紧邻“时间线”标题**，与片段操作同组，不再远放于工具栏末尾。缩放、适应全部留在右侧；统计信息移到下方，不挤占操作按钮。

按钮重新排位不改变新建行为：仍追加到片段序列末尾，默认与前片段重叠 2 秒，用户可随后拖动调整。

## 7. 单行时间线与被动重叠

沿用已认可的 Canvas 几何与命中逻辑，本轮不重写时间线引擎。

所有片段同一行；后片段在共同区间叠在前片段上。顶行显示编号、时长、描述，底边显示待生成、进度或完成耗时。视觉遮挡不是视频合成层级。

拖本体移动，拖边缘裁剪。选中前片段时仍能操作其尾部把手。最多两个相邻片段重叠，不完全吞没其他片段，不产生三重重叠，不增加轨道或隐式重排。

唯一时间事实是整数帧半开区间 `[start,end)`：

```js
const overlapFrames = Math.max(0,
  Math.min(a.end, b.end) - Math.max(a.start, b.start));
```

重叠框只是派生反馈，没有独立选择 ID、输入框、把手或编辑命令。点击框内命中真实片段。

### 引线标注

框下预留独立标注带，以引线连接 `2s` 等时长气泡，框底与标记至少间隔 18px。不能挤在标题、重叠框或进度条上；缩小时避让，必要时优先显示当前片段相关标记。

重叠只表示生成承接的共同时间区间，不自动等于视频叠化、音频交叉淡化或已实现模型连续性采样。

### 生成反馈

生成中显示细进度条、百分比和耗时；结束后显示完成圆点与耗时，具体完成时刻可悬停查看。示例记录标为“示例”，模拟操作标为“模拟”。每片段只记录最近状态，不做版本管理。

进度独立于编辑撤销。移动、裁剪、撤销不回退进度，切换编辑片段不停止其他片段的模拟生成。

## 8. 交互与数据

独立帧运算与双层 Canvas 保持不变。拖动通过动画帧合并绘制，松手一次提交，一次拖动一个撤销；Escape 取消。

吸附用屏幕像素阈值，Alt 临时关闭；Ctrl / Cmd + 滚轮按指针锚点缩放，中键或 H 平移，左右键步进。操作预览媒体原生控件时不触发时间线删除或移动快捷键。

不在每次指针移动时重建全局 DOM 或写磁盘。页面与 Canvas 同源使用完整参考色板，不限制五个颜色，不开放主题设置。

## 9. 项目入口与范围

顶部项目入口保留项目文件夹视觉，不常驻占用编排空间。Demo 仅暂存一个项目，新建项目先说明替换范围。已有任务卡样式不从共享 UI 库删除，但不强行放回本工作区。

本轮没有新增依赖、后端、ComfyUI 连接、真实生成、AI 增强、版本管理、主题 UI 或复杂播放器。保留根目录 `index.html`、相对路径与 `.nojekyll`。

UI 基线以本文为准，01 中历史能力讨论不等于当前实现范围。完整颜色约定见 [03](03_VISUAL_THEME_CONTRACT.md)，演示边界见 [DEMO](DEMO.md)。
