# TerryDirector UI 与时间线架构

> 当前基线：2026-09-28 · Demo v0.3，任务编排工作区。本文替代此前以预览为中心的布局。
> 当前只做 HTML / CSS / JavaScript Demo，不接 ComfyUI、不做 React 拆分。

## 1. 工作台的用途

**编排镜头生成任务，不是实时视频剪辑或预览。**

使用顺序是：在时间线上选择片段 → 编辑该片段的提示词 → 填充参考资产 → 发起生成。

借鉴专业剪辑工具的拖动、吸附、缩放手感，但不照搬监视器、素材浏览器、检查器等整套剪辑布局。用户可见术语统一为“片段”“时间线片段”。

## 2. 三个常驻区域

```text
顶部：项目入口 / 项目名称 / 少量全局操作

┌──────────────────────────────────┬───────────────────┐
│                                  │                   │
│          提示词编辑              │    参考资产填充   │
│                                  │                   │
│ 当前片段 / 用户与 AI 提示词       │ 当前片段已绑定资产│
│ 大面积文本 / 可视化只读预览       │ 从项目选取 / 导入 │
│                                  │                   │
│                   模拟生成       │                   │
├──────────────────────────────────┴───────────────────┤
│                 单行时间线                            │
│ 片段选择 / 移动 / 裁剪 / 自动重叠 / 进度与耗时          │
└───────────────────────────────────────────────────────┘
```

移除常驻视频预览、播放控制条、左侧片段卡片 / 素材浏览列表、右侧整列片段设置。

时间线本身就是片段选择入口，不再用一列任务卡重复选择同一对象。提示词区获得主要编辑空间；资产区只服务当前片段，而不是默认展示整个素材库。生成按钮放在提示词区域底部。

片段名称可在编辑区顶部修改，时长和重叠值只作轻量只读摘要；位置和时长直接在时间线上移动 / 裁剪。分辨率暂保留为提交按钮旁的紧凑控件，不新增“参数面板”。Seed、声音开关、工作流选择等不在当前 Demo 堆成参数墙；已有数据字段不代表已有后端功能。

可拖动提示词 / 资产之间的分隔线，以及时间线高度。窄屏时提示词和资产上下排列，资产区不能直接消失。

## 3. 项目入口及复用边界

顶部项目入口打开项目首页，保留已打磨的项目文件夹视觉，不常驻占用编排工作区。本 Demo 只暂存一个项目，新建项目会先说明替换范围。

已有任务卡片样式不从共享 UI 库删除，但不因为已有组件就强行摆在本工作区中。TerryShotMill 仍为冻结参考；不修改共享 UI 库或 Rulesmd Editor。

## 4. 提示词编辑

保留两组独立选择：

- 用户提示词 / AI 增强：决定本片段使用的内容。
- 文本 / 可视化：同一份原文的编辑 / 只读展示。

默认进入文本编辑，不再让用户先看监视器再寻找编辑入口。切换片段、内容来源或显示模式不能丢字、丢标签。可视化目前只读，不冒充已完成富文本编辑器。

每个片段各自保存两份提示词和当前来源。片段切换不受播放头扫描影响：拖播放头只定位时间，不能把正在编辑的提示词换掉。文本连续编辑在结束编辑时记录撤销，不逐字重绘整个工作区。

“示例增强”只是本地拼入示例文本，明确不调用 AI。生成操作也只演示约 6 秒的进度变化；进度反馈主要在时间线片段底部，不另造一个运行监视面板。

## 5. 参考资产填充

资产区显示当前片段已绑定的图片、视频和音频。缩略图只帮助识别资产，不能变成新的大型监视器。

可直接拖入本地文件或点击导入，导入后立即绑定当前片段；也可临时打开“从项目选取”弹窗，复用已有素材。素材选择器按需出现，不常驻。

点击已绑定资产，在提示词光标处插入对应引用标签。图片 / 视频 / 音频各自编号；移除参考后更新两份提示词内受影响的编号。移除绑定不删除项目素材，也不删除本地文件。参考资产可拖到另一个时间线片段上复用。

本地文件只使用当前页面的 Object URL，不上传；刷新后需要重新导入。当前不提供全尺寸视频 / 音频播放器，不做资产目录管理、转码或代理缓存。

## 6. 时间线保留单行叠放

本次不重新设计已经认可的时间线。沿用 v0.2 的 Canvas、几何及命中逻辑。

所有片段同一行，后片段在共同区间叠在前片段之上。顶行显示编号、时长、描述；底边显示待生成、生成进度或完成耗时。这里的视觉遮挡不是视频合成层级。

用户拖本体移动，拖片段边缘裁剪。按时间顺序命中前景片段；选中前片段时仍能使用它自己的尾部把手。最多两个相邻片段同时重叠，不允许完全吞没其他片段或产生三重重叠，不增加轨道或隐式重排。

### 重叠是被动反馈

唯一时间事实是整数帧半开区间 `[start,end)`：

```js
const overlapFrames = Math.max(0,
  Math.min(a.end, b.end) - Math.max(a.start, b.start));
```

用户移动或裁剪片段，交集自动出现、改变或消失。重叠区没有独立选择 ID、控制把手、输入框或编辑命令。点击框内命中真实片段；下方时长标记也不能反过来修改片段。

### 标注必须拉线

重叠框下方预留独立标注带，以引线连接 `2s` 等时长气泡，框底与标记至少间隔 18px。标记不能挤在重叠框、片段标题或进度条上。缩放时避让；极度缩小时优先保留当前片段相关标记。气泡仅用于反馈。

重叠表示生成承接的共同时间区间，不自动等于视频叠化、音频交叉淡化或已完成的模型连续性采样。

### 生成状态

未开始显示待生成；运行时显示细进度条、百分比和耗时；结束后显示完成圆点与生成耗时。具体完成时刻可悬停查看。示例记录标为“示例”，按钮运行标为“模拟”。

每片段只记录最近状态，不做重新生成的版本管理。进度独立于编辑撤销：移动、裁剪或撤销不回退生成百分比。切换当前片段不停止其他片段的模拟进度。

## 7. 高频交互

继续复用独立帧运算与双层 Canvas，不为缩减面板而重写时间线引擎。拖动通过动画帧合并绘制，松手提交一次变化；一次拖动一个撤销，Escape 取消当前拖动。

吸附阈值以屏幕像素定义；Alt 临时关闭吸附。Ctrl / Cmd + 滚轮以鼠标位置为锚缩放，普通滚轮或中键平移。播放头可拖动及逐帧步进，但不再绑定视频播放器。

不将每次指针移动转成全局 DOM 重建或磁盘写入。Canvas 和页面都读取同一套语义颜色；保持完整参考色板和未来调色接口，不开放主题设置 UI。

## 8. Demo 范围与后续

现在只验证三块区域之间的操作：时间线选择、提示词编辑、资产填充，以及现有时间线手感。根目录 `index.html`、相对资源路径和 `.nojekyll` 保留，零运行依赖，可静态托管。

没有：常驻预览、实时播放、卡片 / 列表浏览侧栏、完整设置检查器、片段版本管理、后端保存、模型调用、真实生成、AI 增强服务、媒体拼接、主题 UI。

以后新增功能必须服务任务编排，不因“其他剪辑软件有”就恢复这些面板。需要查看生成结果时，也先讨论按需入口，而不是重新把视频监视器放回视觉中心。
