# TerryDirector UI 与时间线架构

> 当前基线：Demo v0.5。任务编排为主；生成预览与素材预览分离。
> HTML / CSS / JavaScript Demo，不接 ComfyUI、不拆 React。

## 1. 工作台

常驻区域仍只有：**提示词编辑、参考资产填充、单行时间线**。

基本流程：时间线上选片段 → 写提示词 → 填参考资产 → 生成。

按需预览不能重新成为页面中心。

## 2. 生成预览

“生成预览”指模型采样过程中的中间画面反馈，不是参考素材监看。

参考 ComfyUI-MiniMaxH3-TimelineDirector 的实现：

- SelfLift 路径显式调用 `latent_preview.prepare_callback(model, total_steps)`。
- 低清阶段为兼容 ComfyUI 预览解码器，只把当前 `x0` 临时插值到目标网格后送入 preview callback；真实采样状态仍保持低分辨率。
- 高清阶段继续调用同一 callback，因此低清 / 高清阶段使用同一套 ComfyUI 预览机制。

TerryDirector 正式版应优先消费 ComfyUI 原生生成预览，而不是另外维护一套生成解码管线。

UI 规则：

- 生成预览是显式开关。
- 开启时显示小型悬浮窗，不改变提示词、资产、时间线的布局尺寸。
- 关闭时完全消失。
- 跟随正在生成的片段，而不是跟随参考素材或播放头。
- 生成结束可以保留最后反馈画面，但不扩展成完整播放器、版本管理或剪辑监视器。
- 当前 Demo 用已有静帧配合模糊 / 噪声变化模拟 latent preview，必须明确是模拟。

## 3. 参考素材预览

素材预览与生成预览完全分开。

- 点击参考素材主体打开独立大图 / 媒体灯箱。
- 图片大图适配；视频 / 音频使用原生控件。
- 灯箱覆盖在工作台之上，关闭后释放媒体。
- 不在参考资产栏嵌入预览窗。
- “插入引用”是单独按钮，避免点击素材同时改提示词。
- 素材预览不与时间线联播，也不代表生成结果。

## 4. 提示词与资产

每个片段只有一份提示词，只保留“可视化 / 纯文本”。AI 增强当前移除。

参考资产区只负责从项目选取、导入、查看绑定资产、插入引用、移除绑定。

## 5. 时间线

保持单行 Canvas 时间线：

- 本体移动，边缘裁剪。
- 白色裁剪把手只属于选中片段。
- 重叠由片段位置自动派生，不可直接编辑。
- 重叠时长用引线放在框下方。
- 片段底部显示生成进度和耗时。
- 工具栏按钮使用图标 + 可见文字；新建片段在左侧。

## 6. 外壳和范围

应用四周保留留白和阴影。页面与 Canvas 使用同一主题语义颜色。

Demo 不新增运行依赖、后端、真实模型、版本管理、AI 增强或主题 UI。生成预览开关和素材灯箱都属于临时 UI 状态，不进入项目数据。
