# 使用指南

本指南以 TerryDirector 当前循环器为准。**Base / Advanced 及其专属配置／输出节点已停止注册**。旧工作流如需完整复现，可以在独立工作目录中检出历史提交 `b751b93`；不应把旧代码复制进新版本节点包。

## 1. 首次配置

1. 在 ComfyUI 的 `custom_nodes/TerryDirector` 安装最新版本，并重启 ComfyUI。
2. 使用已有的 H3 模型、文本编码器、视频 VAE 和音频 VAE，按自己熟悉的方式连接采样及解码工作流；TerryDirector 不强制包装这一链路。
3. 创建「TerryDirector 循环开始」和「TerryDirector 循环结束」，将生成／解码链放在循环域中，由「循环信息」传入逐段 Prompt、Seed 和引用资产。
4. 在循环开始节点点击时间线编辑，编排镜头、尾帧承接和提示词；保存后运行。推荐先测一个低分辨率短片段。
5. 输出选择默认 MOV / ProRes 422 HQ，可选 MP4 / H.264。完成后会逐段保存镜头，按需自动合并 Final。

`config_json` 随 ComfyUI 工作流保存；`timeline.json` 随本次实际运行及 MOV/MP4 保存。TerryDirector 不随仓库附带模型权重。

## SelfLift 示例工作流

examples 目录只保留低清、高清、暂停继续三个 JSON 工作流；均使用当前分拆采样节点和通用 LATENT 暂停/继续，不再使用旧专用检查点接口。

| 示例 | 用途 |
| --- | --- |
| [① 低清](../examples/TerryDirector_SelfLift_01_Lowres_Checkpoint.json) | 生成低清，保存 LATENT 缓存及有声审片 MP4；复制检查点 ID 供②使用 |
| [② 高清](../examples/TerryDirector_SelfLift_02_Highres_Resume.json) | 填入①的检查点 ID，从缓存继续高清；没有低清采样分支 |
| [③ 暂停继续](../examples/TerryDirector_SelfLift_03_Pause_Continue.json) | 在同一画布先生成低清，审片后继续高清；预演台配置工作流推荐使用此例 |

低清直接接 MiniMax H3 参考生成视频的 LATENT，高清直接接分辨率选择器的目标宽高，无需另建高清空 LATENT。时长继承低清。三个示例均不绑定本机图片文件，参考媒体端口留空，可以直接接自己的素材。

默认配置：FL2VA BF16、Qwen3VL 32B INT8 ConvRot、视频 VAE INT8 ConvRot、音频 VAE FP32、CFG=1、共享 Seed=8、124 帧，低清 608×352／高清 1216×672。完整日程是 simple 8 步加 Refiner 1 步，低清 6 步、高清 3 步。高清使用 H3 3D Latent Upscaler BF16；空间分块默认关闭。

①运行后，暂停节点会显示检查点 ID，低清有声 MP4 由原生 CreateVideo → SaveVideo 保存到 ComfyUI 输出目录，预演台按本次队列编号及保存节点自动关联。②填入这个 ID，并保持模型、提示词、参考素材、Seed、CFG 与①一致，然后继续执行。③先点击“保存缓存”，确认低清结果后点击“继续执行”。“继续执行”只运行暂停节点之后的高清支路，不调度低清保存支路。普通的全图运行会执行所有输出节点。

更改高清宽高可以复用同一份低清；更改完整 Sigma 日程需要重跑低清。旧 v1/v2 分拆缓存不适用于 v3 接口。导入新例后重新保存预演台的工作流配置；已有缓存不因本次示例重写而失效。

工作流按当前 ComfyUI 原生控件顺序序列化，包含种子／整数控件附带的固定值选项，避免 CFG、宽高及放大器参数错位。模型文件需在本机可选列表中存在。

## 预演台资产选择

预演台按已配置工作流的 API 快照执行，通用暂停/继续与任务管理不依赖 SelfLift 或其专用状态；采样器、步数、SIGMAS、放大器和解码器均由工作流决定。新任务默认沿用工作流的时长及分辨率，无法读取的值显示「沿用工作流」。主动调整时长或分辨率时，只修改本任务线路对应的原始输入源，保留连线和运算；H3 标准帧数表达式修改其上游秒数，不绕过表达式。无法安全映射的自定义运算须在工作流中调整。

替换参考素材时保留已有的缩放、裁切、选帧及音轨处理；共用素材源按当前参考槽位复制所需线路，避免改动其他槽位。未修改的素材和提示词线路保持原样。任务存档保存实际提交的 API 参数，续跑和重跑复用该快照。「载入任务工作流」通过 ComfyUI 的 API 工作流导入器恢复实际提示词、种子、素材和生成参数，节点位置由 ComfyUI 重新排列。采样预览开关只控制预演台记录／显示，不替换工作流的预览节点；采样预览是快速审片，原生 VAE 视频结果由工作流的 CreateVideo → SaveVideo 保存并直接关联，不重新编码。

通用「TerryDirector 暂停/继续」只包含 LATENT 输入／输出、名称、检查点 ID 和运行按钮。暂停时将 LATENT 的 Tensor、noise_mask、batch_index 及附带元数据保存到磁盘并阻断下游；继续时恢复缓存，跳过上游。节点不增加种子输入或输出，也不设置采样、放大或预览参数。旧 `TerryDirectorSelfLiftPauseResume` 已移除，需要换接通用节点并重新保存预演台工作流配置。

SelfLift 使用「TerryDirector SelfLift 低清采样 → 可选的通用暂停/继续 → TerryDirector SelfLift 高清采样」。低清节点直接使用输入 LATENT 的实际尺寸，不再额外缩小；可直接连接 MiniMax H3 参考生成视频的 LATENT 输出。高清节点的 `width` / `height` 指定目标像素宽高（32 的倍数），接双采样分辨率选择器的高清宽高即可，无需单独的高清空 LATENT。时长和音频尺寸继承低清。`low_steps` 指定完整 SIGMAS 前段的实际采样次数，须保留非零过渡 Sigma；高清节点原样执行完整日程的后段 `sigmas[low_steps:]`，`high_steps` 必须等于完整日程步数减去 `low_steps`，不插值或重建 Sigma。例如完整 8 步、低清 6 步，则高清 2 步；完整日程包括 Sigma Refiner 新增的步数。要改变高清步数，应同步修改完整日程总步数并重跑低清。Seed、CFG 在两个采样节点分别设置，学习式放大和空间分块参数归高清节点管理。低清输出的 LATENT 携带原始采样器过渡状态（v3），缓存不绑定高清目标尺寸；修改高清宽高可直接复用低清。保留区域以输入的低清原图／mask 空间缩放到目标网格；已有完整高清原图的保留效果不能由低清反推。通用暂停节点只负责原样缓存 LATENT，不管理种子。复现 selflift-Avatar 时，两段使用相同 Seed、CFG、模型／条件、完整 SIGMAS 与放大器，并让输入低清尺寸与 Avatar 的缩小结果一致，参考路径为 `rho=0`。启用空间分块时，分拆节点与当前 Avatar 一样，在正向条件加入低清全画幅视频参考、使用 6 个 patch 的重叠区域和内容评分切分；这会改变旧空间分块模式的结果。不包含像素 VAE 锚定或 global 模式。

批量添加后，在顶部下拉框按序号选择批次。标题中的「（建议生成时长14秒）」或「（建议14秒）」会自动填入当前批次的视频时长；种子、时长、高清分辨率和预览选项均可逐批编辑。四项参数左侧的同步勾选框默认全不选，同步按钮此时置灰；勾选后点击「同步参数到其他批次」，只复制选中的参数。

参数下方的「工作流预设」用于当前批次，可选择已配置保存的预设。切换会重新检查媒体槽位、种子范围和 VAE 解码能力，保留提示词与资产绑定；每个批次按自己的预设创建任务，预设快照随批量草稿暂存。跨预设同步时，超出目标种子范围或目标预设不支持的 VAE 预览设置会保留原值，并显示提示。

提示词可直接编辑，默认同时可视化批量章节／镜头／命名引用与 H3 语法。绑定图片后，命名引用显示带缩略图的图片胶囊；点击胶囊可替换绑定。点击「</>」切到原文，点击「可视化」切回；切换保留原始标签文本。关闭窗口会暂存各批次的编辑和参数。

创建后，同一次导入的批次收纳在默认折叠的「批次任务」中，展开后按序号从小到大显示；修改、刷新和生成后保留分组。任务类型筛选为「低清／高清」，各任务仍显示实际生成状态；批量运行同样按序号升序提交。

任务条目中的「视频 14 秒」表示该任务计划生成的视频长度，未开始生成时也会显示。采样耗时与进度另行显示。

已完成的任务可点击「继续高清」左侧的「重跑低清」，在紧凑弹窗中填写种子或点击骰子随机生成，再提交重跑。底部「低清重跑」会为所选任务分别生成新种子，并按序号加入队列。重跑保留任务名称、批次归属、提示词、资产及工作流参数，直接删除旧低清视频和检查点，清空其生成记录；排队或运行中的任务不可重跑。若提交队列失败，任务保留为低清待生成，可重新点击「开始预演」。

预演台的新建／编辑任务和批量参考槽位使用同一个资产选择窗口。点击参考资产后，可切换 **input 文件夹** 或 **output 文件夹**，按文件名及子目录搜索图片、视频或音频；列表只按需加载附近的缩略图，滚动接近底部会自动继续加载，也可点击「加载更多」。点击「刷新」可立即获取外部新生成或修改的文件。图片可直接点击缩略图选中；视频卡片显示首帧缩略图，视频和音频点击卡片后先打开播放器，可播放、暂停、调整进度及音量，再点击「使用此视频／音频」确认。「返回列表」或 Esc 关闭预览并停止播放；浏览器不支持的编码会显示提示，仍可选择原文件。上传仍保存到 input。选中 output 文件时，系统会将它复制到 `input/TerryDirector/imported` 后绑定到任务，兼容现有加载节点；原 output 文件保留，重名文件不会覆盖。

## 2. 历史节点迁移

旧版 `TerryDirector` (Base)、`TerryDirectorAdvanced`、`TerryDirectorConfig`、`TerryDirectorSecondPassConfig`、`TerryDirectorOutput` 以及关联的 `.pt` 缓存／分段输出节点已经退休。旧工作流在新版本里可能提示缺失节点，需要转换为当前「循环开始 → 外部采样／解码 → 循环结束」结构，或使用历史版本打开。项目保留 Git 历史以供恢复。

保留共享的 `TerryDirectorSelfLiftSampler` 内部节点及 `director_selflift*.py` 实现；用户也可以直接在循环体内接入现有的 Self-Lift 生成节点。原 Base 二采配置节点不再作为生成参数入口。

## 3. 时间线循环器（外部生成 / 解码链）


循环器是后续版本唯一推荐的视频生成入口：包装普通 ComfyUI 采样／解码链，不内置专属 H3 采样器。循环开始与唯一连通的循环结束之间会自动显示低透明度的 **圆角凸包「TerryDirector 循环域」**：它只是画布背景层的视觉范围，不创建 ComfyUI Group、不改变节点归属和执行逻辑；区域边界按从循环开始向下游可达、并在循环结束处闭合的节点自动计算。循环结束只接收**已经解码完成的 IMAGE/AUDIO**、提取必要承接上下文和逐段编码 MOV/MP4，不再接收 VAE、LATENT 或保存完整视频张量 .pt。

```text
TerryDirector 循环开始
          │ 循环上下文
          ▼
TerryDirector 循环信息
          │ 提示词、采样帧数、Seed、image_0..8
          ├──────────────────────────────→ MiniMaxH3ReferenceToVideo / 自定义生成链
          │ 片段数据
          └─→ TerryDirector 循环条件
                     │
                     │        外部采样 / Self-Lift
                     │               │ LATENT
                     │               ▼
                     │        用户自己的解码节点
                     │          ├─ IMAGE ───────────────→ 循环结束 · 已解码画面
                     │          └─ AUDIO ───────────────→ 循环结束 · 已解码音频
                     │
                     └─ 当前片段元数据由循环器内部传给缓存，不需要接到循环结束

TerryDirector 循环结束
          ├─ 每轮自动保存：clips/001_*.mov、002_*.mov……
          ├─ 合并整片（默认开启）：Final.mov / Final.mp4
          ├─ 视频 VIDEO（合并开启时）
          ├─ 循环记录 Markdown（自动保存报告）
          └─ 片段输出目录 STRING
```

「循环上下文」和「片段数据」是两种不同的接口，不要混接。循环开始只输出循环上下文，循环信息解析成每段的提示词、帧数、Seed、素材及片段数据。循环条件决定如何使用上一段的尾帧和重叠上下文；实际模型、条件、潜变量、采样器、Sigmas 和解码器仍由用户在循环体中自由连接。

循环信息最顶部额外提供 **`index`** 整数输出，表示当前实际循环迭代的 **0 基索引**（0、1、2…），可直接接「从列表获取项目 / Get Item from List」的索引输入；挂起片段不会占用循环索引。循环信息按官方 MiniMax H3 Reference to Video 的额度提供三类参考输出：**9 个图片、3 个视频、3 个独立音频**。端口分别为 `image_0..8`、`video_0..2`、`audio_0..2`。其中参考视频输出类型是官方节点要求的 **IMAGE 帧序列**，TerryDirector 会把 ComfyUI input 中的视频解码并重采样到 24 fps；独立音频输出为 AUDIO。官方还支持每个参考视频额外配一条同编号 soundtrack（最多 3 条），当前循环信息暂不自动输出这组配对音轨，避免改变已有 `<Audio N>` 独立音频编号语义。

循环开始节点支持可选的 **TerryDirector Llama** 输入，与通用提示词增强编辑器共用同一套 AI 推理能力。连接后编辑器中的片段/全局 AI 增强按钮可用；开启「生成前自动AI增强提示」时，循环器会在展开逐段生成子图之前先执行 Queue 前增强，再把增强后的提示词交给循环信息节点。

循环结束对外提供 **最终视频 VIDEO**（合并开启时）、**循环记录 Markdown** 和 **片段输出目录 STRING**。片段文件在**每轮成功后立即保存**到下游 SaveVideo `filename_prefix` 指向的目录，不生成完整 .pt。以 `video/项目/timeline` 为例，同一次任务会生成 `timeline_segments_00001.json`、`timeline_segments_00001_001_镜头名.mov` 等分段，以及可选的 `timeline_segments_00001_Final.mov`；下一次普通运行自动使用 `00002`。这些文件平铺在 `output/video/项目/`，内部任务哈希只保存在 JSON。性能 Markdown 与同名 JSON 继续写入 `output/TerryDirector/reports/`。报告使用真实循环边界的逐片段耗时、ComfyUI 原生采样进度（若有）、资源采样峰值及生成链节点耗时。统计不包括循环结束之后的官方 SaveVideo 编码。它不再输出分段 LATENT，也不再提供「采样结果 / 视频VAE / 音频VAE / 片段数据」输入。

对于 **Self-Lift + 2X VAE** 工作流，推荐接线如下（无需额外接 Video Combine）：

```text
SelfLift / H3 采样 LATENT
        ├─→ LTXVSeparateAVLatent → 清理节点 → MiniMax H3 VAE Decode (fast)
        │                                      │ IMAGE
        │                                      └────────→ 循环结束 · 已解码画面
        │
        └─→ VAEDecodeAudio ─────────────────────────────→ 循环结束 · 已解码音频

```

2X VAE（例如 `MiniMax-H3-X2-Detail-v1.safetensors`）只属于用户自己的 Fast Decode 链。循环结束收到的就是最终解码画面，因此尾帧参考会从这组真实 IMAGE 中提取上一段尾帧。

**可选：TerryDirector H3 2X 低内存解码。** 这个节点由 TerryDirector 自身维护，不修改第三方解码器。需要安装原版 `MiniMaxH3VAEDecodeFast` 作为执行后端；将原工作流中的 `LTXVSeparateAVLatent → MiniMaxH3VAEDecodeFast` 视频支路替换为 `LTXVSeparateAVLatent → TerryDirector H3 2X 低内存解码`，2X 视频 VAE 仍接入新节点，IMAGE 输出依然接「循环结束」和原有视频保存分支，音频支路不变。

新节点将 H3 Latent 按合法时间网格切成带前导上下文的小块，逐块调用**未修改的** FastDecode，再将有效帧复制进唯一的最终 IMAGE 缓冲区；默认每块新增 51 帧、前导上下文 39 帧，空间 Tile 256 / overlap 64，接缝诊断逐帧计算，避免额外完整图像副本。由于 H3 的分块因果上下文可能影响块边界，正式制作前请检查接缝与画质。当前标准 IMAGE 接口仍要求最终整段视频常驻 RAM，所以本方案降低的是峰值而非保证任何时长都无 OOM；真正逐帧写盘还需要更进一步的流式缓存接口。新节点为**可选实验路径，尚未完成用户机器上的完整 GPU 14 段验证**，原有 FastDecode 节点与接线继续兼容。

**格式选择位于「TerryDirector 循环结束」本身**：「片段保存格式」默认 `MOV · ProRes 422 HQ`（10-bit 4:2:2，PCM 24-bit 48kHz 音频），另一选项 `MP4 · H.264`（高质量 H.264 + AAC）。「循环结束合并整片」默认开启，关闭则只输出各镜头文件，VIDEO 端口为空。编码使用 FFmpeg（PATH 下的 ffmpeg 或 imageio-ffmpeg 打包二进制）；无需另接 SaveVideo。旧工作流下游若仍接 SaveVideo，会重复保存；当其输出为 MP4 时，ProRes 整片会转为 H.264 以适配该容器。旧的「循环结束依赖」输入仅用于必须完成的其他旁路副作用，例如额外 VHS 预览，并非逐段保存必需。

**镜头与重叠**：逐段保存的 MOV/MP4 保留原始有效视频（仅删除 H3 采样合法帧数带来的多余尾帧），包括当前镜头开头用于重叠生成的区域。自动合并时依据 `trim_head_frames` **从新片段开头裁掉重叠帧**，保留上一个片段的完整尾部；存在时间线空档时插入黑场和静音。音频统一输出 48kHz，并以每帧对应 2000 个采样点精确裁切；ProRes 视频优先直接复制已编码帧，不再二次有损编码；H.264 由于 GOP 依赖，需要做精确裁切再重新编码最终 MP4。合并前先保存全部镜头文件，合并失败不会删除已有镜头和 `timeline.json`。

### 单镜头重跑与实体视频（循环器）

时间线编辑器中，选中普通生成片段后点击标题栏「仅重跑此片段」，或在片段上右键执行。它不会修改其他片段的挂起状态：后端保留原时间线顺序和承接模式，只复用紧邻的上一有效片段（如确实需要），再执行当前镜头的采样链。

复用已有 MOV/MP4 时，按循环节点 ID、片段 ID、原始帧数查找最新有效结果；文件缺失或帧数不匹配时拒绝运行，不会隐式改成独立生成。尾帧参考/续接取最后 1 帧，重叠衔接取最后 N 帧和对应音频。ProRes 承接从 RGB16 读取并恢复 FLOAT IMAGE，避免先降为 8-bit。

「实体片段」通过编辑器顶部按钮从**已加入资产池的 ComfyUI input 视频**插入。蓝灰色片段不执行 AI 采样；源视频时长经 FFprobe 换算成 24fps 帧数，随后可提供尾帧或重叠上下文。无音轨视频提供静音上下文。

**实体片段默认仅作为上下文锚点，不参与 Final 合并**。因此创作时间线上显示的总长度可能包含不进入成片的实体片段时长。此阶段不把任意帧率、尺寸的视频混入 ProRes 整片；混合素材合并需要后续独立验收。

单片段重跑使用新的五位编号保存 MOV/MP4，**不覆盖旧镜头，也不覆盖既有 Final**。每次任务的编号 JSON 保存 Seed、内部哈希、当前结果、承接模式和上游来源；不生成 OTIO/XML 或剪辑软件工程文件。

### 断点续跑与重跑后的 Final（新开发链路）

- **从中断处继续**：循环节点会在未运行时主动扫描当前 SaveVideo 目录。找到完整时间线、有效片段关系、Seed、参考素材版本、采样工作流、编码格式和保存前缀都完全匹配的未完成任务时，节点显示圆圈感叹号；悬停可见已完成段数。普通运行仍创建新编号，只有用户选择「继续未完成」才复用该任务的**连续已保存片段前缀**。修改 SaveVideo 目录或文件名前缀会被视为新任务。
- **单镜头重跑后重组整片**：若「循环结束合并整片」开启，重新从已有镜头结果中挑选 A、最新 B、C 等 MOV，按照原时间线重叠规则在**本次运行目录**新建 Final；旧 Final 和素材永远不覆盖。若有下游镜头仍引用旧上游 MOV，`timeline.json` 中标记 `stale_downstream`，不会假装镜头已更新。缺失、格式或分辨率不兼容时仅保留新镜头并记录无法合并原因。
- **结果来源**：只使用当前保存目录里的 `timeline_segments_*.json` 和同组 MOV/MP4，不读取旧的 `output/TerryDirector/renders` 隐藏目录。签名可以防止静态配置误用，但不等于能检测模型权重文件内容在原路径被无声替换；需要人工验收最终画质和衔接。
- **验收边界**：本次保存目录与续跑检测变更已通过 CPU/FFmpeg 回归，仍需真实工作流验证。原有恢复链路的 GPU/API 验收记录见基线文档；旧 Base/Advanced 已停止注册。

**资源边界**：循环只保存已完成 MOV、必要的尾帧/重叠音画上下文；不保留完整 .pt。单镜头 VAE 解码和 IMAGE 张量仍可能出现 RAM 峰值。视频输出检查磁盘占用是粗略估算值，不保证最终压缩体积。

**当前范围**：默认适配器是 MiniMax H3；支持官方上限的 9 个图片、3 个视频和 3 个独立音频参考输入。LTX 2.5 仅保留模型适配占位，尚未接通自己的帧数、参考输入和连续性 Guide。循环体中的 Self-Lift、2X VAE、锐化/放大等节点由用户自由搭建。

## 6. 片段与素材

**挂起片段与有效时间线：** 节点预览恢复原先**单行时间线**：未挂起片段保持实际编译时长与衔接，挂起片段仍以原来的灰色半透明、虚线边框片段卡显示在相邻片段之间（保留原始片段序号和名称，点击可定位编辑器）。**预览尺与片段卡宽度恢复原始编排比例**，例如 15 秒片段是 10 秒片段的 1.5 倍；这仅是创作编排预览，不代表最终生成视频含有挂起片段或黑帧。节点顶部的总时长和片段数仍只统计有效片段；Advanced 播放头对应实际生成时间，不会跳进挂起片段。挂起后的下一有效片段直接承接上一有效片段，原本正常片段之间的间隔/重叠仍然保留。编辑器保留完整原始编排，片段 ID、Seed、提示词和素材保持不变。

在节点内点击时间线打开编辑窗口。**播放头只响应顶部时间刻度**的点击与拖动；点击片段区或轨道空白不再改变播放头。可以从轨道空白区域横向拖动框选多个片段（包含片段下方的空白区域），按 Shift 可从片段本身发起框选，按 Ctrl / ⌘ 单击可增减选中片段。选中多个片段后可批量挂起或恢复；在「排序」模式中拖动任一选中片段，会把全部选中片段作为一组移动，保持组内时长、相对间隔与重叠，其他片段让位。**承接模式保存在每个片段自己身上**：排序导致前驱变化、临时空隙、重叠后重新首尾贴合时，原先选择的尾帧参考／尾帧续接／独立都不会自动复位；保存、重新打开及撤销同样保留。将播放头移至目标帧并点击「新建片段」，会在该帧插入完整片段；若该位置之后已有足够空白，后续片段保持原位；只有空间不足才向后推动，若播放头位于旧片段中间，该片段整体后移、不被切开，并保留后续片段内部的间隔和重叠。「排序」模式中被拖动片段固定在实际松手帧，其他片段即时让位，不再有弹性回弹动画；进入排序时自动暂停「后续联动」并置灰，退出后恢复此前的开关状态。时间线支持时长调整、首尾吸附、片段重叠与挂起；「全局提示词」和「片段提示词」可以共同构成每段的生成提示。

片段标题栏现在提供 **Seed** 输入：留空时该片段沿用「TerryDirector 循环开始」节点上的全局 Seed；填写数值后仅当前片段使用自己的 64 位 Seed。右侧骰子可随机生成片段 Seed。该值会随时间线导入/导出保存，并在循环模式中生效；循环信息节点输出的 Seed 也会变为当前片段最终生效的 Seed。

将图片放在共享资产池，通过 `@` 菜单引用。镜头首尾关系包括「尾帧参考」「尾帧续接」「独立」，重叠关系由时间线计算。正在运行的节点编辑窗口会转为只读，但可以继续浏览片段与素材；未运行的其他节点仍可编辑。

ComfyUI → Settings → TerryDirector → 时间线 中可调整默认镜头衔接和尾帧参考提示词模板。


## 可选：AI 提示词增强

本功能不依赖额外安装 `ComfyUI_Qwen_H3_Prompt` 或 `ComfyUI-llama-cpp_vlm` 自定义节点。
仅在使用增强时才需要本机 Qwen3.8 GGUF 权重、对应的 `mmproj` 视觉投影器和兼容的 `llama-cpp-python` Python 包。
默认的 H3 文本/视频生成不要求安装这个 Python 依赖。

1. 将 GGUF 主模型及 `mmproj` 放在 `ComfyUI/models/LLM/`（可使用子文件夹），重启 ComfyUI。
2. 在运行 ComfyUI 的**同一个 Python 环境**中安装与本机系统/Python/CUDA 匹配的 `llama-cpp-python`。Qwen3.8 视觉功能需要支持 `Qwen35ChatHandler` 的构建，可参考 [JamePeng 发布包](https://github.com/JamePeng/llama-cpp-python/releases)；不要在已有 cu130 环境直接覆盖 torch。
3. 添加 **TerryDirector Llama** 节点，选择 GGUF、mmproj、AI Seed（与视频 Seed 独立）。「系统提示词预设」下拉框默认选择 **H3 Skill**；「系统提示词」多行编辑区同时保留 STRING 插口，可直接编辑或从外部文本节点接入。编辑器手动 AI 增强会静态解析常见文本源、ComfyUI 原生 If/Else Switch、**ComfyUI-TerryXu-nodes 的「二路切换器 / 多线切换器 / 联动开关」控制链**，并兼容采用常见 `true/false`、`input_true/input_false`、`route_1..N` / `routes.*` 命名的通用切换节点；Reroute 也会继续向上追踪。Queue 自动增强则直接使用 ComfyUI 实际执行后的 STRING 值，因此任意可执行的上游流程控制节点都由 ComfyUI 自身求值。
4. 系统提示词采用“**自定义文本优先、预设兜底**”规则：只要「系统提示词」去除首尾空白后仍有内容，就完全使用用户文本作为 system role，不再追加 H3 Skill 或 TerryDirector 内置 system/binding 规则；若为空、只有空格／换行／Tab，则视为没有内容，改用下拉框预设。选择「无」且文本也为空时，不发送 system role。连接「Llama」到 **TerryDirector**、**TerryDirector Advanced** 或 **TerryDirector 循环开始** 后，手动增强、全局增强、批量增强和 Queue 前自动增强都遵循同一规则。若 TerryDirector Llama 节点处于 **Bypassed / Never** 状态，编辑器会将其视为不可用配置并禁用 AI 增强相关按钮；恢复启用后自动恢复。
5. 片段的「AI 提示增强」与「一键增强所有提示词」走 ComfyUI 本地 HTTP Job，**不提交 Queue**；片段原文和增强稿分别保存。另提供 **TerryDirector 提示词增强编辑器**：它只是一个简易多行 STRING 编辑器，连接 **TerryDirector Llama** 后，编辑框右下角会启用 ✦ 按钮；点击后直接增强当前文本并写回同一个编辑框，不提供 H3 可视化标签、资产池或时间线能力。增强期间 ✦ 会旋转，再次点击可请求取消。
6. 在「全局提示词」弹窗也可切换「用户提示词 / AI 增强提示词」，点击「AI 提示增强」仅增强**全局人物设定、参考素材关系、摄影/视觉/声音约束**。全局内容不属于一个固定时长的片段，因此输出为适用于所有片段的英文约束说明，而非六节 Ref2VA 镜头输出。原文保留；保存时当前选中的全局版本参与时间线编译以及片段 AI 提示增强。
7. 编辑器顶部开关现名为 **「生成前自动AI增强提示」**。开启后，一次 Queue 自动增强**需要处理的片段**，再执行 H3；全局提示词需要用户在弹窗中**手动点击增强**，不会因运行 Queue 而暗中改写。Queue 自动增强遵循 ComfyUI 自身的 Stop/Interrupt：用户停止工作流时，流式 Llama 生成会在下一个 token 事件检查并立即中断，不再等待整段增强完成；编辑器中的独立手动增强仍只由它自己的取消操作控制。

**AI Seed 规则：** 每个片段在「AI 提示增强」按钮左侧都有独立 **AI Seed**。留空时跟随 **TerryDirector Llama** 节点的全局 AI Seed；填写后，仅该片段的手动增强、一键增强全部以及 Queue 前自动增强使用自己的 AI Seed，右侧骰子可随机生成。片段 AI Seed 会随时间线保存、导入和导出。首次没有结果时会增强；已有 AI 结果且“当前片段最终生效的 AI Seed”相同则复用，Seed 变化时 Queue 自动增强会重新生成。手动按增强按钮始终强制重做对应范围。全局提示词增强仍只使用 TerryDirector Llama 的全局 AI Seed，不读取片段 AI Seed。挂起片段和用户明确选择只使用原文的片段不参与 Queue 自动增强。

AI 仅处理当前片段自身的提示词、时长、当前引用的媒体及启用的全局约束；不提前模拟尾帧、重叠或相邻片段连续性。尾帧/重叠仍由既有时间线编译与采样过程处理。

**媒体边界：** 图片通过 VLM 读取；视频在可使用 OpenCV 时抽样最多四帧供 VLM 观察（未安装解码器时只传媒体名称，不假称已经分析视频）；音频文件目前只传名称，不做听觉内容分析。

**资源提示：** Qwen3.8 27B Q4 会占用大量显存。默认一次只允许一个 AI 推理任务，批量运行只加载一次模型，完成后清理资源。RTX 3090 环境下，基础三段含参考图的自动增强与 H3 视频链路已完成 GPU 实测，详见开发分支的 [AI 验收报告](AI_PROMPT_ENHANCEMENT_ACCEPTANCE_REPORT.md)。**后续新增的全局提示词手动增强仍需单独进行本机 GPU 回归**；GitHub Actions 只验证数据保存、编译行为和模拟 VLM 返回。

## 7. 常见问题

**节点缺失／导入失败**：先核对 ComfyUI 版本、模型和官方生成节点是否安装。已验证的系统版本在稳定基线文档中；其它环境需要自行验证兼容性。

**分段时长与采样帧数不同**：H3 采样长度必须按自己的合法帧数规则对齐，生成后再裁切至时间线需要的帧数，这是正常现象。

**视频输出占用很多磁盘**：循环器不再缓存完整 .pt，独立 MOV/MP4、可选 Final 和少量必要承接上下文会保存在 ComfyUI output。ProRes 422 HQ 是高保真剪辑编码，但并非 Float32 数学无损；请预留足够的输出驱动器空间。

**循环器无法直接接入 LTX 2.5**：目前仅预留 `ltx_2_5` 注册项，未实现帧数规则、Guide、音视频潜变量解码；不能把通用端口名称视为 LTX 已兼容。

**静态演示页无法生成**：根目录 `index.html` 用于预览创作 UI，正式生成请在 ComfyUI 节点图中执行。

生产模块和调用关系见 [架构说明](ARCHITECTURE.md)，稳定运行参数与来源见 [稳定基线](STABLE_BASELINES.md)。


在资产池点击素材可打开占编辑窗口约 80% 的预览；点击「替换资产」并选择相同媒体类型的新文件，会保留原资产 ID 与 `<Picture N>`、`<Video N>`、`<Audio N>` 编号，从而一次更新全部片段和全局提示词中的引用。替换操作可撤销，保存后将新的 ComfyUI input 文件路径写入时间线；网页演示只临时使用本地文件。

资产预览现在支持大图完整适配显示：图片用滚轮围绕指针缩放（100% 为适应窗口，最大 1200%），放大后按住左键拖动平移，双击或点击「适应」复位。视频、音频使用原生播放控件。预览窗口上方可编辑「显示名称」，清空输入并保存即可恢复源文件名；此操作不重命名本机 ComfyUI input 里的文件。资产池、`@` 搜索结果与可视化提示词中的引用标签显示自定义名称；未改名时保持各自原有显示方式。纯文本模式仍保留原始 `<Picture N>`、`<Video N>`、`<Audio N>` 引用，以保证可复制和可生成。显示名称与源文件路径分开持久化，支持撤销／重做、导入导出和保存；全局替换底层文件时不会清除自定义显示名称。
