# TerryDirector 单节点与页内浮窗架构

> 决策日期：2026-10-02；2026-10-05 补充：尺寸改为外接 width / height、移除导演节点预览职责、SelfLift 归入二采方案下拉。  
> 状态：用户确认产品形态与输出约定；实现和兼容性仍需验证，不代表功能已经实现。  
> 当前代码已更新为 Demo v0.6.14 浮窗创作编排稿。本轮仅更新文档，不修改 UI、采样代码、依赖或工作流。

## 1. 本轮确认的形态

用户决定：导演台在 ComfyUI 画布上保留为**一个采样器式主节点**，接入模型和采样参数，输出标准的分段 latent 列表、合并画面和合并音频。节点内显示**只读的迷你时间轴**；点击后在当前 ComfyUI 页面打开大浮窗进行完整编辑，保存退出后隐藏浮窗。

**最新参数归属决定：导演台浮窗只负责创作编排。** TerryDirector 主节点不再内部计算目标分辨率，而是接收外部 `width` / `height`；导演节点本身不承担生成预览；SelfLift 作为“二采方案”的一个选项，默认方案为“无”。

因此：

- 不要求用户连接独立的“规划节点 + 生成节点”。
- 不新开浏览器标签页、窗口或独立工作台端口；生产入口改为当前 ComfyUI 页内浮窗。
- 主节点既是编辑入口，也是实际参与工作流执行的节点，不是单纯的服务启动按钮。
- 时间线、提示词编辑器和资产池继续使用已经打磨的原生 HTML / CSS / JavaScript；不引入 React。
- 实现我们自己的节点，不要求安装、连接或在内部调用 Songssx 的节点类。参考成熟源码进行符合许可的移植、整理与适配，保留来源记录。
- 模型、兼容的加速组件及最终保存由用户在 ComfyUI 工作流中配置；不恢复通用工作流导入、标记、发布、动态 UI 平台。
- **浮窗没有项目层级，也不显示生成预览。** TerryDirector 节点同样不设置预览开关；预览由采样链上的独立预览节点承担。当前编辑器只做创作编排：顶部栏下方先显示单行时间线，再显示“提示词 + 资产池”。
- 不增加自定义结果类型，不要求用户连接 TerryDirector 专用解码节点。

本决策覆盖 `01_PRODUCT_AND_TECH_DECISIONS.md` 与 `06_UI_IMPLEMENTATION_BLUEPRINT.md` 中独立端口、另开网页、画布节点只作入口、浮窗右下生成参数区等旧描述，也覆盖此前两主节点及自定义分段结果 / 专用解码器的候选方案。旧文档和 Demo 用于追溯；未涉及的编辑器、时间线、配色、引用和连续性要求继续有效。QuantFunc 的暂缓接入决定不变。

## 2. 一个可见节点，内部职责仍然分开

画布不拆成两个主节点，不意味着把全部功能写进一个大文件。

```text
页内编辑浮窗 → 已保存的创作编排
                        ↓
节点参数 / 用户外接模型 → TerryDirector 主节点
                        ├─ 分段 LATENT 列表 → 用户的兼容解码 / 精修 / 保存
                        ├─ 合并 IMAGE ──┐
                        └─ 合并 AUDIO ──┴→ 用户的视频合成 / 保存
```

内部按职责整理计划、校验输入、逐段编码 / 采样 / 续接，再完成需要的解码、裁切与合并。这些是同一插件内的代码职责，通过普通数据结构传递，不增加服务或独立任务运行时。正常执行不要求浮窗处于打开状态。

运行实现优先沿用成熟的有限分段展开方式：一次 ComfyUI 提交，在内部保留各段依赖。ComfyUI 的节点扩展机制支持一个可见节点返回内部执行子图，并分别处理子节点缓存。依据：[官方节点扩展文档](https://docs.comfy.org/custom-nodes/backend/expansion)。不因只显示一个节点而另写外部逐段提交队列。

## 3. 画布上的节点外观

外观接近采样器：左侧为必要的模型与参数输入，右侧为 §7 确定的三路标准输出，中间为紧凑参数控件及迷你时间轴。具体输入端口名称、排序和尺寸在实现时确定，不在本轮假定全部接口已完成。

生成参数由节点控件或相应外接输入提供。`width` / `height` 只作为外接输入，不在节点内部重复提供比例 / MP / 倍数或宽高控件；`config_json` 是内部序列化状态，不向用户显示。节点允许按功能组织参数，但不能为了缩短节点高度把它们搬到导演台浮窗。

迷你时间轴：

- 显示已保存的片段排列、相对时长、重叠，以及片段数 / 总时长摘要。
- 只读；不提供拖动、裁剪、重排、资产投放或另一套时间线编辑手势。
- 点击迷你时间轴打开编辑浮窗；“编辑”按钮直接放在“时间线”标题行右侧，不再单独占用一整行。
- 有真实执行数据时才显示进度与结果状态；迷你时间轴不是视频播放器，不用素材缩略图伪装生成结果。
- 缩小画布时降低文字细节，不频繁重画完整编辑器。关闭浮窗后只更新必要的节点摘要。

完整编辑器与迷你时间轴读取同一份保存数据；可以复用时间几何计算，不能因此把完整编辑命中区域带到只读视图中。

## 4. 同页大浮窗

浮窗视觉与时间线代码以 `408395e7620fe368775515ca515d04fae7a8daed`（Demo 06.11）为恢复基线。当前将单行时间线整体放到“提示词 + 资产池”工作区上方；时间线 Canvas、核心交互和 200px 默认高度继续沿用该提交，不从 06.12 / 06.13 的工作区重构代码拼接时间线。：只负责创作，不设置生成参数

点击节点入口后，在当前 ComfyUI 页面显示大浮窗，遮罩下面的画布；不使用 `window.open`，不跳转地址，不启动第二个 Web 服务。

大浮窗以视口为基准，不随节点画布缩放。ComfyUI 内嵌模式使用较小的居中窗口，外围为半透明毛玻璃，让下方 ComfyUI 画布仍能辨认；关闭按钮放在窗口内部标题栏，紧跟“保存并退出”右侧。继续使用现有 Studio Dark、圆角和单行时间线，不重新发明编辑器。

**正式浮窗移除旧 v0.6.13 的右下生成参数区。** 目标尺寸由外部 `width` / `height` 输入提供；二采方案位于主节点；导演节点不提供预览启用设置。浮窗不保留第二份控件、只读参数表或动态设置面板。移除参数区后的空间用于现有创作区域，具体分栏比例在迁移时确认，不额外加入模块。

保留的内容为时间线、片段内容与时长编辑、提示词、项目资产池和引用、素材查看、必要编辑操作及保存退出。片段的起止时间和由位置产生的重叠属于创作编排，仍在时间线上编辑；时间线缩放、吸附、后续联动和可视化 / 原文切换不是生成参数，不因本条决定删除。

素材灯箱继续服务于参考选择，但 TerryDirector 不再承担生成预览功能；预览交给采样链上的独立节点。浮窗内不提供模型、步数、种子、生成模式、尺寸或二采设置。

建议实现方式：使用 ComfyUI 前端扩展，在页面顶层挂载独立、带样式作用域的原生 DOM 容器。扩展生命周期参考[官方前端扩展说明](https://github.com/Comfy-Org/ComfyUI_frontend/blob/main/docs/extensions/core.md)。不能把当前 Demo 的 `body`、`#app` 全局样式直接注入 ComfyUI，不能覆盖宿主页面根节点。

交互要求：

- 编辑器中的输入、拖动、滚轮、复制、删除和撤销不得穿透到背景画布；保留中文输入法行为。
- 焦点留在浮窗内，退出后回到原节点入口。素材灯箱和菜单位于编辑浮窗之上，Esc 先关闭内部弹层，不直接丢弃整个编排。
- “保存并退出”提交编辑结果、更新节点摘要并隐藏界面；不是开始生成。旧 Demo 的主生成动作不保留为浮窗底栏，使用保存退出。
- 关闭按钮或 Esc 遇到未保存修改时，应提示保存、放弃或继续编辑；点击遮罩不能静默丢失内容。
- 再次打开恢复该节点已保存的编排及合理的编辑位置。一个编辑浮窗绑定一个明确的工作流节点实例；复制节点、切换工作流或删除节点不能误写另一节点。
- 隐藏时暂停编辑器动画、媒体播放及不必要的监听；后台已经提交的生成继续。生成状态留在节点本体或 ComfyUI 运行反馈中，不在浮窗新增生成预览区域。

根目录静态 Demo 可以继续作为样式和交互预览入口，但它不是生产运行必须打开的第二个网页。两种承载方式复用编辑器代码，不维护两份业务 UI。当前 Demo 尚未删除参数区，不能把本次文档修改表述为 UI 已完成迁移。

## 5. 保存、排队和运行的边界

已保存的创作编排放在该节点的可序列化输入中，包含版本、片段、原始提示词、稳定素材引用和时间位置。生成参数作为节点控件 / 输入保存，不再混入浮窗草稿维护第二份可编辑值。后端能从本次执行输入取得完整配置，不依赖浏览器内存或当前选中片段。

编辑浮窗使用创作草稿副本。保存后原子更新节点的正式编排值，并通知 ComfyUI 工作流已修改；不覆盖节点上的生成参数。这不等于已自动保存到用户磁盘，磁盘保存继续遵循 ComfyUI 工作流的实际机制。

队列执行使用提交时快照：

- 保存退出不自动排队，也不重复提交工作流。
- 有未保存草稿时，不允许把它悄悄当成已保存计划提交；正式入口应提示先处理草稿。
- 已排队 / 正在执行的任务不因打开编辑器、切换片段、修改节点参数或再次保存而变化；后续修改影响下一次提交。
- 运行信息按本次任务及节点实例关联，不能仅以“当前选中节点”判断归属。
- 工作流内保存的是配置与媒体引用，不嵌入模型、图片二进制、视频张量或浏览器 `blob:` 地址。导入素材需有后端可读取的持久文件引用。

当前 UI Demo 的页内暂存、片段分辨率及导出版本 9 的 `project.latentUpscale` 只是迁移来源。正式格式须有向后兼容处理；旧值互相冲突时明确迁移 / 提示，不静默丢弃，也不让旧字段暗中覆盖节点输入。本轮不冒充已完成持久化或迁移。

## 6. 参数归属与 SelfLift

主节点接受 `MODEL`、`CLIP`、必要的视频 / 音频 `VAE`、采样器及采样调度等输入。以下确定归属，不表示已新增全部参数或冻结最终端口列表：

| 内容 | 所在位置 |
| --- | --- |
| 模型、编码器、VAE、采样器、调度 | ComfyUI 节点输入 / 用户已有工作流 |
| 目标宽高 | 外部 `width` / `height` 输入端口；TerryDirector 内不再提供比例 / MP / 倍数或宽高输入框 |
| Seed、参考图尺寸、音频连续等实际支持的采样参数 | 节点控件或相应外接输入 |
| 二采方案 | 节点下拉菜单，默认“无”；当前可选 `SelfLift` |
| SelfLift 放大模型、高清占比 | 仅当二采方案选择 `SelfLift` 时显示 |
| 生成预览 | 不属于 TerryDirector；由采样链上的独立预览节点负责 |
| 片段顺序、起止时间、重叠、提示词、素材引用 | 导演台创作浮窗 |

外部已连接的参数是该次执行的实际来源。浮窗不显示或编辑参数，也不维护任何可以覆盖节点值的副本。采样调度从外部 `SIGMAS` 取得时，高清阶段步数按实际总步数校验，不能再使用一个互相冲突的内部总步数。

SelfLift 类渐进二采保留在主节点的内部采样部分：当“二采方案”为“无”时按普通路径采样；选择 `SelfLift` 时执行低清阶段、潜空间提升和高清阶段，然后进入相同的分段结果与音画合并输出。优先沿用已核对的成熟 H3 实现并保留连续性，不要求用户在成品 latent 后再接一个新节点来替代采样中途的加速。

现有“二次潜空间放大”设置足以表达这项已确认能力，不另加一个“Self 技术”浮窗面板。原目标分辨率语义、SelfLift 高清占比和 H3 放大模型兼容性约束继续保留；作用范围为该导演台节点的整组执行，不在浮窗恢复片段独立参数。具体采样器限制随采用版本验证。

技术来源：[Songssx `_selflift_settings`（固定 a81f13b）](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector/blob/a81f13b8af4a162467cec4dc377f40b7354d7ffc/minimax_h3_finite_segments.py#L43-L91)、[其二采运行实现](https://github.com/Songssx/ComfyUI-MiniMaxH3-TimelineDirector/blob/a81f13b8af4a162467cec4dc377f40b7354d7ffc/selflift_runtime/nodes.py)。参考代码不等于本项目已完成 GPU 验证。

主节点仍然需要 VAE：参考素材编码、部分二采 / 承接以及合并 IMAGE / AUDIO 输出都可能使用它。模型与 latent 格式、尺寸、音视频遮罩及模型补丁必须兼容；标准端口不等于任何 H3 工作流都能无条件替换。

## 7. 三个标准输出：不新增专用解码体系

用户已确认以下三个输出，取代此前待定的自定义结果包方案：

| 输出名称 | 标准类型 | 内容与用途 |
| --- | --- | --- |
| 分段潜变量 | `LATENT`，声明为 ComfyUI 原生列表输出 | 按时间线顺序，每项为一段完整的最终 H3 AV 采样 latent，保留用于承接的重叠部分；用于已有解码、精修或分段保存节点 |
| 合并画面 | `IMAGE`，普通输出 | 内部按编排完成解码、裁切、重叠去重与合并后的最终帧批次 |
| 合并音频 | `AUDIO`，普通输出 | 内部处理完成、与合并画面对齐的最终音轨 |

普通出片用后两路连接现有视频合成 / 保存节点；进一步处理分段素材用第一路。**不自定义 `TD_SEGMENTS` 等外部类型，不要求使用我们自己的专用解码节点。** 内部仍可保留必要的计划、片段身份、重叠、时序和原音锁定数据，但不把内部结构变成用户必需的外部协议。

列表里的每项须为标准 latent 字典，`samples` 承载对应的 H3 AV latent，而不是把整个 Python 列表塞进单项 `samples`。使用原生列表输出声明，使支持相应 H3 格式的下游普通节点逐项处理；后两路不随之变成分段列表。列表机制依据：[ComfyUI 数据列表文档](https://docs.comfy.org/custom-nodes/backend/lists)。

上轮核对的原生 `VAEDecode` 对嵌套 latent 取视频路，`VAEDecodeAudio` 取音频路，分别接正确的 H3 VAE。固定源码入口：[视频解码](https://github.com/Comfy-Org/ComfyUI/blob/fa98a189b4271c76f66210e15f81790b555eb610/nodes.py)、[音频解码](https://github.com/Comfy-Org/ComfyUI/blob/fa98a189b4271c76f66210e15f81790b555eb610/comfy_extras/nodes_audio.py)。安装版本和实际接线仍须本地验证，不泛化到不兼容的第三方解码器。

分段 latent 列表不是已去重的长视频。直接逐项解码再顺序连接会保留各段重叠内容；需要准确复现导演台最终编排时，使用合并 IMAGE / AUDIO。SelfLift 的低清 carry 是内部续接数据，不能冒充最终高清 latent。末段 latent 也不代表整个项目。

第一版按既定成熟路径逐段解码、处理接缝并合并，不自动引入“按场景选择 latent 拼接策略”的额外分支。以后若研究合并 latent，另行验证其帧网格和音视频一致性，不改变当前三个输出的含义。

输出列表不保证逐段即时流式执行，未连接的输出也不能被假定自动跳过计算。实现时需核对执行图、缓存、解码开销与内存，避免重复采样 / 解码；本轮不为优化增加新 UI 或承诺恒定内存。

## 8. 参考与实现红线

- Songssx 等仓库是实现参考与可依许可采用的来源，不是本项目运行时必须安装的导演台节点包；所有本项目内部 helper 与节点标识由 TerryDirector 自己提供。
- 保留现有计划校验、原始提示词与素材编号转换、前序 latent、音视频遮罩和二采上下文语义。换成单节点不能简化成互不相关的多条提示词。
- 不为表面端口兼容而移除连续性约束，不把上一段尾帧需求误记成参考实现已经满足的行为。
- 前端编辑、mini 时间轴、Python 执行模块分工保持清晰；一个可见节点不等于一个源文件。
- 生成参数只在节点，不因后来引入新技术、参数变多或更新 UI 而放回浮窗；不增加动态参数平台、自定义结果类型或必需的专用解码器。
- 不新增独立端口、第二进程、外部调度器、工作流管理平台、React 或后台技术监控。
- [QuantFunc](08_QUANTFUNC_RESEARCH.md) 继续暂缓；本次改架构不自动授权接入它。

## 9. 后续验收顺序
