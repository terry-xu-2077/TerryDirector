# 信息层级配色 · 普通 / 紫色 / 橙色

> 当前基线：v0.6.9 选中片段与背景投影修订。取代此前按“编辑 / 生成 / 时间”分区用色的规则。
> 保留参考图完整源色板；外侧回到此前深灰蓝，以更明显的投影表现悬浮感。

## 三个级别

| 级别 | 色彩 | 使用对象 |
| --- | --- | --- |
| 一级：普通 | 灰蓝表面、白 / 灰文字 | 正文、普通标题、资产卡片、参数输入、实际分辨率、未激活按钮、完成记录 |
| 二级：关注 | 紫色，配克制的紫色浅底 / 边线 | 编辑焦点、当前模式、启用工具和预览开关、结构与运镜定位、播放头、吸附与重叠关系 |
| 三级：最高 | 小面积暖橙 | 选中的时间线片段、主生成按钮、任务关键进度反馈、提示词内的资产引用 |

层级取决于信息重要程度，不取决于它属于哪个功能区。预览下面的分辨率也是一级读数；开启预览只是二级状态，不应与主生成按钮一样抢眼。提示词内的资产引用属于需要突出检查的实际输入，图片、视频、音频引用统一暖橙；台词块单独使用珊瑚红作内容区分，不是报错或新增优先级。保留关系仍保持中性。

橙色不能铺在整块面板上。普通内容占绝大多数，紫色负责定位，橙色最少。不要给每个区域都安排一个橙色焦点来凑比例，也不另设粉色 / 绿色作为第四、第五级。

## 当前组件映射

- 分辨率结果：从暖色恢复为中性文字、内凹底与普通边界；依然实时计算。
- 预览开关：开启用紫色，关闭用普通中性；不隐藏窗口，不影响生成。
- 提示词结构、镜头与运镜：保持克制紫色；说话人、时间和关系说明保持中性。
- 图片 / 视频 / 音频引用：暖橙文字、淡橙底与细边框；悬停沿用同色高亮。只改编辑器内的引用标签，不把资产池卡片全部染橙。
- 台词块：珊瑚红语言标签、淡红底与细边框；台词正文保持白色，便于阅读和编辑。红色是台词内容标识，不触发错误状态。
- 所有标签几何、原文、菜单、复制与导出保持不变。
- 选中的时间线片段：三级橙色边线，低饱和暖色渐变填充，不把整条轨道涂橙。普通片段仍为中性色，白色裁剪把手不变。
- 时间线的播放头、重叠框 / 短引线 / 秒数和吸附：继续二级紫色，与橙色选中片段明确区分。
- 生成按钮及任务关键进度：保留参考图的暖金 / 橙色。时间线完成记录回归中性，使用状态文字区分完成与待生成。
- 菜单：普通说明与分类图标中性，当前菜单项 / 输入焦点用紫色。

错误或无效输入保留必要的状态提示与文字，不以“普通”颜色隐藏错误。这是异常语义，不另建装饰色层级。

## 主题接口

`src/theme.css` 保留完整 Source Palette，新增优先级语义入口：

```css
--td-level-1-ink
--td-level-2-ink
--td-level-2-soft
--td-level-3-ink
```

既有 `resolution-*`、`generation-*`、`tag-*`、`timeline-*` 变量通过统一主题控制。`--td-tag-reference` 映射三级暖橙，图片 / 视频 / 音频共同消费；`--td-tag-dialogue` 映射源色板的 `--td-warm-coral`，与错误状态 token 独立。DOM 和 Canvas 继续消费同一主题，不把配色散落到业务逻辑，不开放主题设置 UI。

应用外背景恢复此前约 `#242632 → #1D1F29`，不再用近黑铺满外围。投影使用深色阴影：较宽的下方柔和投影，加近处接触阴影，让工作台外壳浮起。留白、圆角、内部表面与三列宽度不变；颜色与本轮外壳投影统一放在 theme.css 的产品样式映射中，不改变布局尺寸。

## 同轮调整：短引线

重叠框下边缘到时长气泡上边缘的距离由 18px 缩短到 8px。气泡保持 23px 高，水平避让继续沿用已有逻辑；引线转折点在间隔中点，不越过气泡。时间线默认高度、片段高度、裁剪命中区、被动重叠及后续联动均不变。
