# 配色修订 · 灰蓝 / 紫 / 暖橙

> 基于 v0.6.8，仅调整主题与颜色映射，不改变布局、数据或交互。
> 本文补充 03 的完整源色板；当前角色映射以本页及 `src/theme.css` 为准。

## 参考图的取色与分工

沿用用户提供的音乐插件参考：灰蓝外壳与深色内凹区域承载内容，紫色用于编辑焦点，暖橙用于操作与数值反馈，粉紫保留给时间线定位和重叠。不是把全部紫色换成橙色，也不铺满橙紫渐变。

原色板里的 `#9D5E21` / `#6C472D` 是偏暗的暖色，不能替代参考图中明亮的橙色指针与读数。本轮针对这些小区域重新取样，补充两枚近似源色：

- 暖金 `#E59B3D`：来自 SUB 2 指针区域的暖色像素中位数。
- 橙色 `#E07D2B`：来自 TONE 指针区域的暖色像素中位数。

截图存在渐变与抗锯齿，取样不是原设计文件的精确色值。默认暖色读数由暖金和亮文字色混合提亮，约为 `#E8AC5F`。原灰蓝、紫蓝、粉紫、珊瑚和暖棕色板全部保留，不限制源色数量。

## 界面用色

| 区域 / 状态 | 当前映射 |
| --- | --- |
| 主面板 | 继续使用 `#343747`；不把工作区域压成黑色 |
| 编辑器 / 预览内凹区 | 灰蓝基色混合，约 `#272A37`，强化内外层次 |
| 普通悬停 | 中性灰蓝，不再给每个普通按钮染紫 |
| 当前片段 / 编辑工具 / 引用高亮 | 紫色边界；选中片段填充降低亮度和饱和度 |
| 播放头 / 自动重叠 / 引线气泡 | 保留粉紫，继续突出时间定位，不改变语义 |
| 生成按钮 | 小面积暖金至橙色渐变，配深色文字；悬停与键盘焦点同组 |
| 实际分辨率标签 | 暖色读数、低透明暖色背景和细边界 |
| 生成预览开关 | 开启状态为暖色，关闭仍为中性灰；区域始终保留 |
| 生成进度 | 预览下方与 Canvas 片段内均使用同源暖色 |
| 完成 / 异常 | 完成仍是灰绿，异常仍是珊瑚色，不拿橙色代替所有状态 |
| 提示词 | 语法 / 运镜保留紫系；音频参考使用暖金，对白保留粉珊瑚色 |

灰蓝仍占绝大多数面积。紫色表达“正在编辑哪里”，暖橙表达“生成与输出反馈”；粉紫是少量的时间标记。不为凑颜色给所有面板、标签和按钮添加高饱和填色。

## 更暗的浏览器背景

新增中性源色 `--td-neutral-night: #08090D`。应用外侧从约 `#0C0D12` 渐变至 `#08090D`，明显深于工作台，但不改已经确定的留白宽度。外壳亮边稍收敛，阴影改用这一深色源，避免旧灰蓝阴影在近黑背景上显得发灰。

## 实现范围

颜色全部集中于 `src/theme.css`，通过 `generation-*`、`resolution-*`、`tag-*`、`timeline-*` 语义变量供 DOM 与 Canvas 消费。末尾只绑定产品颜色，不写尺寸、排布或事件，不覆盖共享 UI 库内部样式。

`app.js`、编辑器、时间线、分辨率计算和资产逻辑完全未改。未新增主题设置、动画、框架或后端。页头的交互版本仍为 06.8，本次为该版本的配色修订。
