# TerryDirector 批次提示词 Markdown 规范（TBPM）

TBPM 是 TerryDirector 批量预演任务的轻量 Markdown 输入约定。使用标准 Markdown，不使用 XML、JSON 或自定义标签语言。

## 文档级全局规则

使用一级标题 `# 全局规则`。其下内容会按批量导入窗口的选项附加到每个批次。

## 批次

每个批次使用独占一行的二级标题：

```markdown
## 批次01｜菌伞峡道·赛车穿越机（建议15秒）
```

编号应唯一并按顺序递增。标题中的建议时长可省略；省略时默认 15 秒。

## 批次内章节

以下章节均为可选项，顺序可以按创作需要调整。未识别的普通章节内容会保留。

### 导演说明

描述本批次的戏剧意图、叙事目的和观众体验。

### 引用资产

每项资产使用一条列表：

```markdown
- 图片：`00_特瑞_Terry.jpg` — 特瑞面容、沙棕旧披覆外层及深灰工装
- 音频：`荒原风声.wav` — 荒原环境风声
- 视频：`FPV参考.mp4` — 赛车式穿越机运动参考
```

类型仅使用图片、音频、视频。文件名必须使用反引号包裹，并与资产库中的文件名一致；`—` 后为可选描述。

### 待生成资产

每项待生成资产使用四级标题，提示词放在独立代码块中：

````markdown
#### 图片｜干燥菌伞峡道母图｜2.39:1

提示词：

```text
请生成一张2.39:1横幅的真人写实电影空间母图……
```
````

图片需要画幅比例，例如 `2.39:1`、`16:9`、`1:1`；音频和视频不需要比例。一个批次可以有多个待生成资产。

### 其他推荐章节

- `### 连续性状态`：人物、载具、场景和道具的连续性。
- `### 视觉基调`：摄影机运动、人物表演、空气流动、衣料物理等。
- `### 色彩光影`：色彩、光线和环境氛围。
- `### 分镜脚本`：镜头编号、时间、景别、焦段、运镜、画面和声音。

## 解析行为

- `# 全局规则`：提取为文档级全局提示词，按用户选项附加到每个任务。
- `## 批次NN｜名称`：创建独立任务；任务名沿用标题名称，建议时长提取自标题。
- `### 引用资产`：提取媒体类型、文件名和描述；最终 H3 提示词中转换为 `<Picture N>`、`<Audio N>`、`<Video N>`，各媒体类型分别编号。
- `### 待生成资产`：提取类型、名称、比例和完整提示词；从最终 H3 提示词中剥离，独立提取并显示在批次配置窗口，不占用工作流媒体输入槽。
- 已知章节标题转换为提示词中的方括号章节标签；其他普通章节保留其标题和正文。
- 批次配置窗口展示原始批次 Markdown；最终任务提示词使用清理后的正文。
- 解析错误必须明确显示，不能静默丢弃内容；原始文档始终保留。
- 兼容旧版 `批次01｜名称` 纯文本标题及 `[全局参考]` 格式。

## 示例

````markdown
# 全局规则
高预算实拍真人科幻剧集质感。人物、载具和环境保持真实物理表现。

## 批次01｜菌伞峡道·赛车穿越机（建议15秒）

### 导演说明
用赛车式穿越机的自由飞行把观众带入异星峡道。

### 引用资产
- 图片：`00_特瑞_Terry.jpg` — 特瑞外观
- 图片：`蚂蚱载具.jpg` — 866载具外观

### 待生成资产
#### 图片｜干燥菌伞峡道母图｜2.39:1

提示词：

```text
请生成干燥菌伞峡道的真人写实电影空间母图……
```

### 连续性状态
866四轮完好，翼膜收拢。

### 分镜脚本
镜头01｜[0–15s] 18mm，独立穿越机一镜到底……
````

TBPM 只约定必要的结构标记。普通正文仍可使用 Markdown 列表、粗体、引用和自然段落。
