# Demo v0.4.1 · 外壳留白与选中裁剪把手

## 当前范围

HTML + CSS + JavaScript 静态 Demo，零运行依赖。三个常驻区域为提示词、参考资产、单行时间线。可选参考预览在资产区内部展开，默认关闭。没有以视频为中心的大监视器、片段列表侧栏或设置检查器。

本轮移除 AI 提示词增强、示例增强、双来源切换及其数据。只有一份提示词，在“可视化 / 纯文本”间切换。当前不做片段版本管理。

## 操作

1. 在时间线上选片段；默认纯文本编辑，切换可视化只读展示。
2. 导入或拖入图片、视频、音频，或从项目选取参考。点击资产主体插入引用；“移除”只解绑并更新编号。
3. “显示预览”打开当前片段参考；也可点击资产的“预览”。图片、视频、音频均支持，视频 / 音频采用浏览器原生控件，不自动播放。标明非生成结果。
4. 关闭预览立即清空媒体，恢复资产空间；切换片段或素材、解绑预览素材、返回项目首页时停止旧媒体。编辑提示词不打断同一素材的播放。
5. 所有时间线工具按钮都有名称；“新建片段”位于左侧，缩放 / 适应全部在右侧。新建仍默认追加末尾并重叠 2 秒。
6. 时间线沿用移动、裁剪、吸附、缩放、撤销与被动重叠；重叠时长由引线放在框下方。
7. 模拟生成约 6 秒，只演示进度与耗时，不生成真实视频。刷新还原，配置导出不包含媒体文件或预览开关。

## 静态入口

仓库根目录 `index.html` 可配合 `src/`、`assets/` 直接托管；`.nojekyll` 和相对路径保持不变。下载包同时提供内联单文件 `打开Demo.html`，无需安装或构建。

## 样式和媒体来源

`src/studio.css` 是 Terry UI / Studio Dark 的静态视觉快照，来源版本 `39b5f91d8b34c9fc55659def96ca76968e0de52b`。不运行 React 组件，不修改共享 UI 库或 Rulesmd Editor。

完整源色板集中在 `src/theme.css`。`TerryDirectorDemo.applyTheme({...})` 仅为现有开发验证入口，没有用户主题设置或持久化。

预置发射场图来自 scikit-image `data.rocket()` 中的 SpaceX DSCOVR / Falcon 9 照片，原数据说明标记为公有领域；星空为 SVG 占位。均是参考素材，不是模型结果。来源说明沿用此前版本：

- https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket
- https://www.flickr.com/photos/spacexphotos/16511594820/in/photostream/
