# Demo v0.5 · 生成预览与素材灯箱

## 本轮变化

- 移除参考资产栏内嵌预览。
- 点击参考素材主体打开独立大图 / 视频 / 音频灯箱。
- “插入引用”改为单独按钮。
- 生成按钮旁新增“生成预览”开关；开启后显示悬浮小窗，关闭不占布局。
- 模拟生成时，悬浮窗用已有参考静帧配合模糊 / 噪声变化模拟 latent preview。
- 正式版计划复用 ComfyUI 原生预览。参考项目 SelfLift 路径通过 `latent_preview.prepare_callback` 接 ComfyUI preview callback，并在低清阶段只为预览临时抬升 `x0` 网格。

## 仍然保留

提示词可视化 / 纯文本、参考资产填充、单行时间线、移动、裁剪、吸附、被动重叠、引线时长、生成进度与耗时。

## 明确没有

真实 ComfyUI 连接、真实 latent 预览、视频生成、片段版本管理、AI 增强、媒体转码或时间线联播。
