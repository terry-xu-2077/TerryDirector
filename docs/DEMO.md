## 使用

根目录 `index.html` 为静态入口，保留 `src/` 和 `assets/` 的相对位置。下载包里的 `打开Demo.html` 为相同代码的内联单文件。无安装或构建步骤。

上方从左到右依次为提示词编辑、项目资产池、固定生成预览。下方时间线不变。预览窗口始终保留，默认开启；开关只控制画面显示 / 更新，不影响任务进度和区域尺寸；窄屏保持同顺序上下排列。素材点击仍打开独立灯箱。

提示词默认可视化且可以编辑。输入 `@` 从整个项目资产池引用素材，输入 `/` 调出 H3 语法；继续输入可搜索。方向键选择和进入分类，Enter / Tab 确认，Esc 关闭。点击标签可以更换参考、编号、时间或运镜；对白内容与语言可以直接编辑。纯文本模式共用同一份原文，也支持两个菜单。

全部来源命令与说明见 [H3_EDITOR_PORT](H3_EDITOR_PORT.md)。
