# Demo v0.2 · 单行叠放与生成状态

## 范围

这是用于讨论 UI 的静态 Demo，不是已运行的导演插件。没有网络请求或模型调用。发布到 Pages 只是展示网页，不能访问用户的本地 ComfyUI。

本页展示的“生成”“增强”、进度与耗时都明确标注为演示。当前不做片段版本管理，没有版本切换或版本集合。预置画面是静帧，不代表真实的长视频续写效果。示意波形不是从音频抽样产生的波形。

## 操作

- 片段同一行叠放；拖本体移动，拖片段边缘裁剪；自动重叠不接收编辑事件。
- 重叠时长通过引线放在框下方，预留独立标注带，不与框或底部进度条挤在一起。
- 点击「模拟生成当前片段」，约 6 秒内演示进度；底边实时显示进度条。完成后改为生成耗时；悬停片段可查看完成时刻。重试只更新本次状态，不新增版本。
- S 切换吸附；拖动期间按住 Alt 临时关闭吸附。
- Ctrl / Cmd + 滚轮缩放，普通滚轮平移；也有缩放按钮与底部滚动条。
- 中键或 H 进入平移；V 返回选择工具。
- Space 预演 / 暂停时间线；左右键步进一帧，Shift 加左右键步进一秒。
- Ctrl / Cmd + Z 撤销；Shift + Z 或 Ctrl + Y 重做。一整次拖动只记一步。
- Delete 删除；Escape 取消尚未提交的拖动。
- 片段卡片和时间线选择联动。进入文本模式编辑提示词，可视化模式只读显示相同原文。
- 点击素材预览；双击素材或拖到时间线片段上添加参考。图片、音频、视频使用本地 Object URL，不上传。
- 本地视频 / 音频在独立原生播放器中预览，不与当前时间线实现完整同步播放。
- 导出的 JSON 包含片段、参数和提示词，不包含媒体；本地素材需要重新导入。当前没有导入该 JSON 的产品流程。
- 分隔线可以调整面板宽度或时间线高度；双击分隔线恢复默认。

时间线以 24 fps 作为 Demo 时间基准，区间统一为半开区间。一秒最小时长是本次交互限制，不是模型合法性验证。

## UI 库来源及边界

`src/studio.css` 的文件夹、片段卡片、标签、胶囊选择器与滑动标签几何来源于 Terry UI / Studio Dark：

- 参考版本：`39b5f91d8b34c9fc55659def96ca76968e0de52b`。
- 参考文件：`src/studio/components.tsx` 与 `src/studio/studio-dark.css`。
- 仓库：<https://github.com/terry-xu-2077/Terry_React_UI_Library>。

本次为了无需安装和构建，采用静态 DOM 视图适配，不打包 React、不伪装成已安装 React UI 包。快照中产品颜色改为集中语义变量，没有修改 UI 库原始代码。Demo 保持原生 HTML / CSS / JavaScript，不拆为 React 工程；正式产品整合以后另行讨论，不把快照发展成平行 UI 库。

`src/core.js` 与 `src/timeline.js` 不依赖视图库，后续 React 可以在面板挂载时创建时间线，在卸载时调用 `destroy()`。

## 颜色与媒体来源

所有 UI 颜色来自用户确认的参考色板及必要的可读性 / 状态补充，集中在 `src/theme.css`。不提供主题设置页面；开发者可以通过 `TerryDirectorDemo.applyTheme({...})` 验证公开源色映射和 Canvas 重绘，参数为允许的源色 CSS 变量。此入口不保存主题。

预置发射场图片为 SpaceX 的 DSCOVR / Falcon 9 照片，经 scikit-image 的 `data.rocket()` 示例数据取得并压缩为 WebP。scikit-image 官方数据说明将此图标记为公有领域；原始归属仍为 SpaceX，不表示任何代言。

- 数据说明：<https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket>
- 原始图片：<https://www.flickr.com/photos/spacexphotos/16511594820/in/photostream/>

多个片段复用同一张图。星空为本 Demo 自绘 SVG 占位。素材配色不是 UI 主题的一部分。

## 验证记录与限制

本轮检查针对单行时间线的帧范围、相邻片段重叠、禁止三重重叠、裁剪边界、标注引线、命中顺序、生成进度与版本入口移除。Node 检查不需要安装依赖：

```sh
node --test tests/*.test.cjs
```

浏览器检查使用 Chromium 内联载入与入口相同的 HTML / CSS / JS。环境阻止了文件 URL 导航，不能把该检查等同于双击文件入口或线上 Pages 部署已验证。没有访问用户的 ComfyUI、GPU 或模型，也不宣称已达到 Premiere 级媒体播放性能。

还没有：片段版本管理、多选框选、分割、拖到屏幕边缘自动滚动、完整键盘时间线对象树、完整媒体帧同步、代理缓存、波形分析、真实生成与保存后端。以上不在当前 Demo 中伪造完成。
