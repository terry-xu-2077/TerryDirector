# Demo v0.3 · 任务编排工作区

## 当前范围

HTML + CSS + JavaScript 静态 Demo。工作区只常驻提示词编辑、参考资产填充和单行时间线。去掉常驻监视器及播放控制、片段列表、素材浏览侧栏、完整设置检查器。无网络请求、框架依赖或模型调用。

项目首页保留文件夹视觉，从顶部入口按需打开。生成与示例增强均为模拟，进度不代表真实任务；重新生成不创建版本集合。刷新页面还原，配置导出不包含媒体文件。

## 操作

1. 在时间线上选择片段，上方显示对应提示词和参考资产。
2. 默认文本编辑；可切换到只读可视化。用户 / AI 两份内容独立保存，当前标签决定使用哪份。
3. 拖入文件或点击导入，立即填充当前片段。也可临时打开“从项目选取”复用素材。
4. 点击资产插入对应引用标签。移除参考只解绑，并更新两份提示词中的编号；不删除素材文件。
5. 时间线保持单行、本体拖动、边缘裁剪、被动重叠与下方引线时长。重叠没有独立把手。
6. 模拟生成约 6 秒，进度和完成耗时在时间线片段底部显示。切换编辑对象不停止模拟。
7. Ctrl / Cmd + 滚轮缩放，中键或 H 平移，V 选择，S 吸附，Alt 暂停吸附，F 适应全部；左右键移动播放头，Ctrl Z 撤销，Ctrl Shift Z / Ctrl Y 重做，Delete 删除，Esc 取消拖动。
8. 分隔线调整资产区宽度或时间线高度，双击恢复。没有实时媒体播放；播放头只用来定位时间。

## 样式和媒体来源

`src/studio.css` 是 Terry UI / Studio Dark 的明确标注静态快照，来源版本 `39b5f91d8b34c9fc55659def96ca76968e0de52b`。保留项目文件夹、提示标签和参数控件的视觉语言；不用 React，不修改共享 UI 库或 Rulesmd Editor。任务卡片样式不删除，但不在当前工作区常驻展示。

UI 完整色板集中在 `src/theme.css`，不限定五个源色。开发者可用 `TerryDirectorDemo.applyTheme({...})` 验证语义变量和 Canvas 颜色，没有主题设置或主题持久化。

预置发射场图来自 scikit-image `data.rocket()` 示例中的 SpaceX DSCOVR / Falcon 9 照片，压缩为 WebP。原数据说明标记为公有领域，归属仍为 SpaceX。星空是本 Demo 的 SVG 占位；它们只是参考素材，不是模型结果。

- https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.rocket
- https://www.flickr.com/photos/spacexphotos/16511594820/in/photostream/

## 本轮验证

`src/core.js`、`src/timeline.js` 与 v0.2 保持相同内容。现有 21 项 Node 帧运算 / 时间线检查通过：

```sh
node --test tests/*.test.cjs
```

Chromium 实际操作检查覆盖：三块区域与旧面板移除、时间线选择联动、提示词来源与显示模式切换、资产选取 / 解绑 / 引用编号、本地导入、片段拖动与一步撤销、模拟完成、项目首页、窄屏资产区和空项目新建。被检查流程未出现页面脚本错误。

浏览器环境阻止了 `file://` 导航，检查使用由相同 HTML / CSS / JS 内联生成的单文件页面，不等同于已经验证双击入口或线上 Pages 部署。没有访问 ComfyUI、GPU 或模型，不宣称真实视频生成或专业媒体播放性能。

仍未实现：后端保存、真实生成、片段版本、多选批量移动、分割、完整键盘对象树、拖动边缘自动滚动、视频同步、转码及音频分析。当前不为这些增加占位面板。
